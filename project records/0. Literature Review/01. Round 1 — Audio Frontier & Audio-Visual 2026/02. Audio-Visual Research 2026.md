## 1. 感知（Perception）

### 1.1 Audio-Visual Speech Enhancement（音视觉语音增强）

#### ★★★ Separate First, Then Associate (2608.14812, 2026-08-14)
- **作者**：eess.AS
- **核心**：**A Two-Stage Approach for Real-World Audio-Visual Speech Enhancement**。
- **问题**：现有 AVSE（Audio-Visual Speech Enhancement）在 simulated 数据集上表现强，但 **real-world 性能急剧下降**。
- **方法**：
  - **Stage 1：先做 separation** — 把混合语音分离成单说话人音频流。
  - **Stage 2：再 association** — 用视觉模态（lip / face）把分离结果与目标说话人关联。
- **关键洞察**：把"分离"与"增强"解耦，先保证 separation，再做 visual-guided association，显著提升 real-world 鲁棒性。
- **与 FullDuplexLLM 关系**：双工系统中"边听边分离"是核心能力，本工作的"分离 + 关联"二阶段思路可借鉴到 barge-in 检测 + 目标说话人保留。
- **为什么必读**：2026 AVSE 唯一系统化 real-world 鲁棒性工作。

### 1.2 Egocentric Multi-Talker ASR（第一视角多说话人识别）

#### ★★★ SLT 2026 SmartGlasses Challenge (2608.12034, 2026-08-12)
- **作者**：Dehui Gao, Zhixian Zhao, Zhennan Lin, Yujie Liao, Yuhang Dai et al.
- **核心**：**Egocentric Multi-Talker Speech Recognition and Understanding with Audio-Language Models**。
- **任务**：
  - TSA-ASR（time-stamped speaker-attributed ASR）
  - Track 1：双人对话
  - Track 2：多人会议
  - 设备：智能眼镜，**第一视角**
- **核心挑战**：
  - **Dynamic acoustic conditions**（走动 / 头部转动）
  - **Speaker overlap**（多人同时说话）
  - **Spatial ambiguity**（声源空间定位）
- **为什么读**：**第一视角 + 多说话人 + 实时性** 是双工对话的真实场景约束，本工作定义了 2026 评测标准。

#### ★★ tttAI System (2607.17867, 2026-07-20)
- **核心**：SmartGlasses Challenge 2026 参赛系统 — 同时支持 Track 1 和 Track 2。

### 1.3 Audio Reasoning with Vision（视觉证据辅助音频推理）

#### ★★★ VISA (2606.07264v2, 2026-06-05) — **本轮 review 的核心论文**
- **作者**：Wenming Tu, Jian Gao, Yanru Huo, Yixuan Wang, Jing Peng et al.
- **核心**：**Visual Information Strengthened Audio-Reasoning System for Interspeech 2026 ARC Agent Track**。
- **架构范式**："**LALM as a Tool**" — LLM-based agent 调度 LALM + 视觉证据做 multi-step reasoning。
- **关键贡献**：
  - **不是简单 feature concatenation**，而是 **tool-use paradigm**。
  - 让 audio reasoning 拥有"视觉证据"作为辅助工具。
  - 在 Interspeech 2026 ARC Agent Track 上提交（MMAR Rubrics 评估）。
- **为什么读**：
  - **2026 唯一一份"以音频为主、视觉为辅"的 agentic reasoning 框架**。
  - 与本项目 FullDuplexLLM 的"双工核心 + 视觉证据"思路直接对应。
  - 提供了一个具体的 system design 可参考。
- **与 FullDuplexLLM 关系**：
  - 把"工具调度"思路迁移到 Full-Duplex Spoken Dialogue：LALM 是核心，turn-taking、barge-in、backchannel 等是 tool。
  - 视觉（lip / facial expression / scene）作为辅助证据。

### 1.4 Multimodal Emotion / Ambivalence Recognition（多模态情绪 / 含糊识别）

#### ★ ABAW11 Multimodal Ambivalence (2607.15779v2, 2026-07-17)
- **核心**：**Multimodal Ambivalence and Hesitancy Recognition via Cross-Attention and Gated Fusion**。
- **任务**：识别视频中的 **A/H（Ambivalence/Hesitancy）** — 即"含糊 / 犹豫"状态。
- **融合**：textual + acoustic + visual modalities + BAH dataset + cross-attention + gated fusion。
- **为什么读**：副语言识别的最高难度 — A/H 是介于"是"与"否"之间的状态，与双工对话的 barge-in / backchannel 时机判断直接相关。

### 1.5 Speech-Driven Gesture Generation（语音驱动手势生成）

#### ★★ GENEA Challenge 2026 (2608.10839, 2026-08-11)
- **作者**：cs.CV / cs.GR / cs.HC / cs.SD
- **核心**：**The GENEA Challenge 2026: A Large-Scale Disentangled Evaluation of Speech-Driven Gesture Generation on the Seamless Interaction Dataset**。
- **关键贡献**：
  - 第四次 GENEA Challenge。
  - **Seamless Interaction dataset** — dyadic conversations（双人对话）。
  - **Large-scale human evaluation** of 5 systems。
  - Disentangled evaluation（解耦评估）。
- **为什么读**：co-speech gesture 生成是"audio-to-visual"的核心任务之一。

#### ★★ Super Star (2608.24909, 2026-07-22)
- **作者**：cs.HC, cs.CV, cs.SD
- **核心**：**Towards Streaming Real-time Interactive Agents for Digital Humans**。
- **关键贡献**：现有 co-speech gesture generation **多为 offline**，但真实数字人需要 **streaming real-time**。
- **为什么读**：与 FullDuplexLLM 的 streaming 要求对应。

### 1.6 Polyglot Speaker ID with Missing Modality（多语言多模态说话人识别）

#### ★★★ POLY-SIM 2026 Evaluation Plan (2603.24569v2, 2026-03-25)
- **核心**：**Polyglot Speaker Identification with Missing Modality Grand Challenge 2026**。
- **关键贡献**：
  - 假设现实场景中模态**不完整**（视觉被遮挡、音频被噪声污染）。
  - 单人可能说多语言。
  - 与传统 multimodal speaker ID 的"完整模态"假设不同。

#### ★★ POLY-SIM 2026 Insights (2607.13669, 2026-07-15)
- **核心**：**Learning Speaker Identity Beyond Language and Modality Constraints**。
- **关键贡献**：POLY-SIM challenge 的 lessons learned 总结。

### 1.7 Audio-Visual Forensics（音视觉取证）

#### ★★ AIGC Audio-Video Detection (2607.25543, 2026-07-28)
- **作者**：cs.CV, cs.AI
- **核心**：**Less is More: Modality-Decoupling for General AIGC Audio-Video Detection**。
- **关键洞察**：
  - 现有 AIGC audio-video detection 假设 **cross-modal inconsistency**（音频和视频不对应）。
  - **本文实证发现这个假设不成立** — 现代 AIGC 模型生成的 audio-video 已经高度一致。
  - 提出 **modality-decoupling**：单模态检测比 cross-modal 检测更鲁棒。
- **为什么读**：颠覆性发现 — 改变了音视频 deepfake detection 的设计哲学。
- **与 FullDuplexLLM 关系**：未来双工系统的"音频真实性"检测需要重新设计，不能简单依赖 cross-modal inconsistency。

## 2. 生成（Generation）

### 2.1 Native Multimodal Audio-Video Generation（原生多模态音视频生成）

#### ★★★ Seedance 2.0 (2604.14148, 2026-04-15)
- **作者**：字节跳动
- **核心**：**Advancing Video Generation for World Complexity**。
- **关键贡献**：
  - **2026-02 中国发布**的原生多模态音视频生成模型。
  - 比 Seedance 1.0/1.5 Pro **统一架构**，**大模型**，**高效**。
  - 支持 **4 种输入模态**：text / image / audio / video。
  - **统一架构** 处理 text-to-video、image-to-video、audio-to-video、video-editing。
- **为什么读**：2026 多模态音视频生成的**旗舰工业模型**，是 FullDuplexLLM 项目的"对照天花板"。
- **与 FullDuplexLLM 关系**：
  - 字节 / 阿里 / OpenAI 都把多模态音视频生成作为旗舰能力，本项目可对标。
  - Seedance 2.0 的"4 模态统一"思路值得借鉴到双工架构设计。

### 2.2 Vision-Language Audio Embeddings（视觉-语言-音频嵌入）

#### ★★ V-SONAR (2603.01096, 2026-03-01)
- **核心**：**Unified Vision-Language Modeling via Concept Space Alignment**。
- **关键贡献**：
  - 在 SONAR（text-only embedding space）上扩展到 **vision-language embedding space**。
  - 支持 **1500 text languages + 177 speech languages**。
  - **V-SONAR** 是首个支持此规模多语言 / 多模态的 embedding space。
- **与本项目关系**：基础能力层 — 全双工对话系统的视觉 / 语音 / 文本理解统一嵌入空间。

### 2.3 Audio-Video Safety（音视频安全）

#### ★★★ Multi2AV-Safety (2608.26535, 2026-08-27)
- **核心**：**Benchmarking Safety in Multimodal-to-Audio-Video Generation**。
- **关键贡献**：
  - Audio-video generation 从 prompt-driven → **multimodal conditioning**。
  - 同一份 safety 评估的对象变了：harmful input 可以从 text / image / audio / video 任意组合。
  - 提出首个 multimodal-to-AV 安全评测 benchmark。
- **与本项目关系**：未来多模态双工对话系统的安全性评估基础。

## 4. 综合性发现（Findings & Insights）

### 4.1 音视觉研究的三大趋势

**趋势 1：从"特征级融合"到"工具级调用"**
- 老范式：audio feature + visual feature → concat → fusion network。
- 新范式（VISA 路线）：LALM 作为 tool，由 LLM-based agent 调度 audio + visual 两个 tool 做 multi-step reasoning。

**趋势 2：从"静态融合"到"流式 / 第一视角"**
- 老范式：offline AVSR / AVSE / gesture generation。
- 新范式：SmartGlasses Challenge 第一视角、Super Star 流式手势、AlignAtt4LLM 同步 ST。

**趋势 3：从"假设完整模态"到"假设模态缺失"**
- POLY-SIM 2026 把"missing modality" 设为前提，**承认现实不完美**。
- 与此对应，AVSE 在 real-world 性能下降的问题 (2608.14812) 也强调"sim-to-real" 鸿沟。

### 4.2 三大开放问题

**Q1：跨模态推理的"证据"机制如何设计？**
- VISA 给出"tool-use" 范式，但其他架构（如 Cross-Attention、Cross-Modal Attention）仍是主流。
- 2026 论文尚未系统对比。

**Q2：AIGC 音视频的真实性检测如何应对"跨模态高度一致"？**
- 2607.25543 提出 modality-decoupling，但只验证了 detection 任务。
- 是否适用于"辨别 AI vs human 实时生成" 待研究。

**Q3：第一视角音视觉系统在双工对话中的延迟如何控制？**
- SmartGlasses Challenge 强调 first-person + multi-talker，但**端到端延迟**尚未标准化。

### 4.3 音视觉研究与本项目 FullDuplexLLM 的对应表

| FullDuplexLLM 子方向 | 对应 2026 论文 | 借鉴点 |
|---|---|---|
| 双工控制 / turn-taking | HumDial-EIBench (2604.11594) + ABAW11 A/H (2607.15779) | EI + 含糊状态识别 |
| 流式 ASR | SmartGlasses (2608.12034) + AlignAtt4LLM (2606.03967) | first-person + sync ST |
| 视觉证据推理 | VISA (2606.07264) | tool-use paradigm |
| 多模态生成 | Seedance 2.0 (2604.14148) | 4-modality unified arch |
| 副语言合成 | GENEA 2026 (2608.10839) + Super Star (2608.24909) | disentangled + streaming |
| 安全检测 | AIGC detection (2607.25543) + Multi2AV-Safety (2608.26535) | modality decoupling + multi-input safety |

## 5. 推荐阅读顺序（针对 FullDuplexLLM）

1. **VISA (2606.07264v2)** — 视觉证据辅助音频推理的代表，提供 tool-use 范式参考。
2. **Separate First, Then Associate (2608.14812)** — 真实场景下的音视觉分离 + 增强。
3. **Seedance 2.0 (2604.14148)** — 工业界多模态生成旗舰，了解 SOTA 上限。
4. **SmartGlasses Challenge (2608.12034)** — 双工 ASR 的真实场景约束。
5. **AIGC Detection (2607.25543)** — 颠覆性发现，重新审视"跨模态不一致" 假设。
6. **POLY-SIM 2026 (2607.13669 + 2603.24569v2)** — 多语言多模态说话人 ID 的现实场景设计。
7. **GENEA 2026 (2608.10839) + Super Star (2608.24909)** — 副语言手势的 disentangled + 流式评估。
8. **Multi2AV-Safety (2608.26535)** — 多模态→音视频的安全评测。
9. **V-SONAR (2603.01096)** — 多语言多模态嵌入空间。
10. **ABAW11 A/H (2607.15779v2)** — 含糊/犹豫状态识别（与副语言高度相关）。
