| 评估指标（FID, IS, CLIPScore） | **音频 FAD / CLAP / AudioScore 改进** | ★ |

## 三、从 stakeholder rotation 视角出发的缺口

### 3.1 终端用户缺口
- 找不到"音频编辑工具"（audacity 太原始、Pro 工具太贵）→ **AI 音频编辑**
- 找不到"个人音频 IP 保护工具" → **音频水印 / provenance**
- 找不到"实时音频增强"（去噪 + 修复 + 增益）→ **一体化 audio enhancement agent**
- 找不到"音频内容检索"（基于语义找相似声音）→ **audio semantic retrieval**

### 3.2 开发者缺口
- 音频 diffusion 比文本 diffusion 难部署 → **audio diffusion distillation / acceleration**
- 音频模型难以 debug → **interpretability of audio LALM**
- 音频数据稀缺（特别是版权音乐）→ **audio data augmentation / synthesis**
- 音频评估指标不可信（FAD/CLAP 都已被质疑）→ **new audio evaluation paradigm**

### 3.3 监管者缺口
- AI 生成音频如何追溯？→ **watermarking standard**
- AI 音频是否合规？→ **policy + technical standard**
- 音频生成内容审查？→ **safety filter for audio generation**

### 3.4 攻击者 / 红队视角
- 当前 audio deepfake detection 是被动 → **proactive defense via watermarking**
- 扩散模型的对抗样本 → **audio adversarial robustness**

## 四、跨领域灵感池（Cross-Pollination）

| 源领域 | 类比思路 | Audio 应用 |
|---|---|---|
| **图像生成**：ControlNet | 用控制信号（边缘、深度、姿态）细粒度引导生成 | Audio ControlNet — 用 MIDI / score / rhythm / emotion embedding 引导音乐/语音生成 |
| **图像生成**：IP-Adapter | 用 reference image 提取风格 | Audio IP-Adapter — 用 reference audio 提取音色/风格 |
| **图像生成**：Inpainting | 图像部分重绘 | Audio Inpainting — 音频片段重绘 |
| **视频生成**：长视频一致性 | 跨帧 identity + 场景一致性 | 长音频 / 多说话人对话的 identity 一致性 |
| **3D 生成**：NeRF | 隐式神经场 | 空间音频隐式神经场（HRTF 个性化） |
| **RL / RLHF**：文本 RLHF | 人类偏好对齐 | 音频 RLHF（人类对音色 / 自然度 / 节奏的偏好） |
| **Agent**：文本 agent (ReAct) | 多步骤 tool 调度 | 音频 agent — LALM 调度 ASR + TTS + Music + Detection 工具 |
| **检索增强**：RAG | 用外部知识增强 | 音频 RAG — 用音乐库 / 声音库增强生成 |
| **对抗训练**：图像 GAN | 对抗损失 | 音频 GAN-free 蒸馏 / 对比学习 |
| **神经隐式表示**：SDF / Occupancy | 隐式场表示 | 音频隐式场（连续表示替代离散 token） |

## 五、关键 Tension 列表（来自 brainstorming F3 framework）

| Tension | 是否 fundamental | 现有 artifact 程度 |
|---|---|---|
| Latency ↔ Quality | 部分 fundamental（受物理约束） | 部分 artifact — streaming diffusion 仍可探索 |
| Compression ↔ Fidelity | partial fundamental | artifact — 神经 codec 替代传统 |
| Generality ↔ Specialization | artifact | 大模型 fine-tune 路径已通 |
| Safety ↔ Capability | artifact | 已有 RLHF 等 |
| Discrete ↔ Continuous token | artifact | diffusion codec 可突破 |
| Streaming ↔ Offline | artifact | causal codec 可突破 |

| Open ↔ Closed | artifact | open-source 路径已通 |

## 六、初始候选列表（15+ 方向，按来源分类）

### A. AIGC 直接迁移类（6 个）
1. **Audio Latent Editing** — 像 SD img2img / DragGAN 那样编辑音频的 latent
2. **Audio ControlNet** — 用结构化控制信号（MIDI、rhythm、emotion embedding）引导音频生成
3. **Audio IP-Adapter** — 用 reference audio 提取风格，跨音色生成
4. **Audio Inpainting / Outpainting** — 填补损坏 / 扩展音频
5. **Audio GAN-free Distillation** — 把扩散音频蒸馏到 1-step / few-step
6. **Audio Watermarking / Provenance** — 给生成音频加水印 / provenance

### B. 跨界融合类（4 个）
7. **Audio-Visual Generation Beyond Seedance 2.0** — 学术级音视频联合生成
8. **Audio Agentic System** — LALM 调度多 audio tool 的 agent
9. **Audio RAG** — 用检索增强音频生成（音乐推荐 + 风格匹配）
10. **Audio RLHF Scaling** — 大规模人类偏好对齐音频模型

### C. 现有 audio 痛点类（3 个）
11. **Audio Reasoning + AIGC** — 把 DeepSeek-R1 reasoning 思路迁移到音频 CoT，但用 AIGC 方式生成
12. **Audio Diffusion Streaming** — 流式 / real-time 音频扩散生成
13. **Audio Interpretability** — LALM 的可解释性 / 故障分析

### D. 基础设施类（3 个）
14. **Diffusion Audio Codec** — 用 diffusion 替代 RVQ，实现更高保真 + 可编辑
15. **Spatial Audio Generation** — ambisonic / HRTF 个性化生成
16. **New Audio Evaluation Metric** — 替代 FAD / CLAP 的可信评估

### E. 安全 / 反 AI 类（2 个）
17. **Audio Adversarial Defense** — 对抗样本下的鲁棒性
18. **AIGC Audio Provenance Standard** — 行业标准 + 技术实现
