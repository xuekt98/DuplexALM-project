## Top 5 推荐（按优先级排序）

### ★★★★★ #1. **Audio Latent Editing**（音频潜空间编辑）

**Priority Score：9.2 / 10**

- **AIGC 匹配度**：★★★★★（SD img2img / DragGAN 是 AIGC 核心能力）
- **团队互补度**：★★★★★（既不是 duplex ALM 也不是 music gen，**完美差异化**）
- **2026 行业信号**：★★★★★（arXiv 2026 检索 "audio editing" 返回 0 篇 — 真空）
- **痛点真实度**：★★★★（音乐人 / 播客 / 影视后期都需要）
- **复杂度合理度**：★★★（需要重建 codec 的可编辑性，但可控）

**Two-sentence Pitch**：
> 音频领域目前缺乏 SD img2img / DragGAN 那样的**潜空间细粒度编辑**能力——音乐人和后期只能"重录"或"剪掉"，无法"局部改写"。
> 我们通过在神经 codec 的 latent space 上做（解耦的）语义 + 声学双空间编辑，实现"只改音色不改旋律"或"只改情绪不改内容"，让音频编辑像图像编辑一样民主化。

**与团队合作的潜在接口**：
- 与 duplex ALM 团队：用 LALM 解析编辑指令（"把这段变忧郁"）→ 转化为 latent 编辑信号
- 与 music gen 团队：编辑与生成共享同一 latent codec

**2-Week Pilot**：
1. Week 1：基于现有 neural codec（SoundStream / WavTokenizer / SpeechTokenizer），实现 latent space inversion（任意音频 → latent）
2. Week 1：用 linear probing 验证 latent 是否解耦（音色 / 内容 / 节奏维度可分）
3. Week 2：在解耦维度上做 controlled editing demo（"改音色不改音高"），找 10 个 listener 做 ABX test
4. **可交付物**：一个 latent editor 原型 + 一份 "what's possible" demo 集

**Reference 借鉴**：
- 图像：SD img2img, DragGAN, LEDITS, PnP
- 视频：DragAnything, ReVideo
- 音频：仅有零星工作（Wav2Clip latent manipulation 等）

### ★★★★☆ #2. **Audio Watermarking / Provenance for AIGC**（AI 生成音频的水印 / 来源追溯）

**Priority Score：8.7 / 10**

- **AIGC 匹配度**：★★★★★（图像水印已成熟，音频滞后）
- **团队互补度**：★★★★★（不重叠 duplex / music）
- **2026 行业信号**：★★★★★（VoxENES 2026 指出 LLM-era TTS 让旧 spoofing benchmark 失效；Multi2AV-Safety 首次系统化 audio-video safety）
- **痛点真实度**：★★★★★（监管 / 平台 / 用户都明确需要）
- **复杂度合理度**：★★★（需要 robustness vs imperceptibility tradeoff，但可控）

**Two-sentence Pitch**：
> AI 生成音频的快速普及（LLM-era TTS、voice cloning、Seedance 2.0 类多模态生成）让"区分真声和 AI 声"从学术问题变为监管和平台刚需，但当前 deepfake detection 是被动且易被规避。
> 我们提出**主动 provenance 范式**——在生成阶段嵌入鲁棒且不可感知的水印（含模型指纹 + 时间戳 + 来源标识），让每段 AI 音频自带"出生证明"，从 detection 转向 prevention-first。

**与团队合作的潜在接口**：
- 与 music gen 团队：训练 pipeline 嵌入 watermark 损失
- 与 duplex ALM 团队：双工生成的实时水印（低延迟 embedding）

**2-Week Pilot**：
1. Week 1：复现 Tree-Ring / Gaussian-Shading（水印到频谱）→ audio 版（spectrogram / neural codec latent）
2. Week 1：在 5 种常见攻击（mp3 压缩、重采样、变速、拼接、轻微改写）下测 robustness
3. Week 2：在 3 个 codec-based TTS（CosyVoice / VALL-E / 真实语音）上做 end-to-end 测试
4. **可交付物**：一个 audio watermarking library + 一份 robustness benchmark

**Reference 借鉴**：
- 图像：Tree-Ring, Gaussian-Shading, Stable Signature
- 视频：VideoShield, Watermark Anything
- 音频：AudioSeal, WavMark, Proactive Detection 等零星工作

### ★★★★☆ #3. **Audio Diffusion Streaming + GAN-free Distillation**（流式音频扩散 + 无 GAN 蒸馏）

**Priority Score：8.4 / 10**

- **AIGC 匹配度**：★★★★★（扩散模型蒸馏是 AIGC 经典，SD-Turbo / Consistency Models 思路直接迁移）
- **团队互补度**：★★★★（与 duplex ALM 高度互补——后者需要流式低延迟 TTS）
- **2026 行业信号**：★★★★（audio diffusion 是热方向，但**流式**仍是空白）
- **痛点真实度**：★★★★（实时音频生成是双工对话刚需）
- **复杂度合理度**：★★★（consistent distillation 是已有方法，迁移成本低）

**Two-sentence Pitch**：
> 当前音频扩散模型（Tango / AudioLDM / Stable Audio）的推理延迟通常 1-10 秒，无法用于**实时**场景（双工对话、流式音乐创作）。
> 我们把 SD-Turbo / Consistency Models / Latent Consistency Models 的"少步蒸馏"思路迁移到音频扩散，让音频生成也能在 **1-4 step 内**完成实时推理（<100ms latency）。

**2-Week Pilot**：
1. Week 1：选一个开源音频扩散 baseline（AudioLDM 2 / Tango 2），实现 consistency training
2. Week 1：测不同 step 数（1, 2, 4, 8）下的 FAD / CLAP / 推理速度
3. Week 2：在流式场景测试（chunk-by-chunk 生成 vs 一次性生成），验证听感质量
4. **可交付物**：一个 1-step 音频扩散 demo + benchmark

**Reference 借鉴**：
- 图像：SD-Turbo, Latent Consistency Models, DMD2, ADD
- 音频：仅有初步 consistency training 探索

### ★★★★☆ #4. **Audio Agentic System**（音频 agentic 系统）

**Priority Score：8.0 / 10**

- **AIGC 匹配度**：★★★★（text agent 已成熟，audio agent 是 2026 唯一 VISA 论文）
- **团队互补度**：★★★★★（与 duplex ALM 高度互补——agent 是 LALM 之上的 orchestration 层）
- **2026 行业信号**：★★★★（VISA 是唯一一篇，但标志方向开始出现）
- **痛点真实度**：★★★★（复杂音频任务需要多步骤工具调用）
- **复杂度合理度**：★★（需要构建 tool 生态）

**Two-sentence Pitch**：
> 当前 LALM（大音频语言模型）只能"听+答"，无法"听+调用工具+多步骤推理"——而真实场景的复杂音频任务（"找一首相似风格的 BGM 并把它剪成 30 秒"）需要 ASR + retrieval + editing + generation 多步协作。
> 我们构建 **Audio Agent** 范式——以 LALM 为大脑，把 ASR / TTS / music retrieval / audio editing / generation 等作为可调度 tool，实现 audio 的 ReAct / tool-use reasoning。

**2-Week Pilot**：
1. Week 1：定义 5-10 个 audio tool（ASR, TTS, separation, editing, retrieval）作为 function calling API
2. Week 1：在 LALM（Qwen2-Audio / SALMONN / 现有 duplex 模型）上做 SFT 让它学会 tool 调用
3. Week 2：定义 20 个 complex audio task（"找到相似音乐+降噪+剪辑"），测试 agent 成功率
4. **可交付物**：一个 audio agent demo + tool library

**Reference 借鉴**：
- 文本 agent：ReAct, Toolformer, Gorilla, OpenAI Function Calling
- 视觉 agent：Visual ChatGPT, MM-ReAct, HuggingGPT
- 音频 agent：仅 VISA 1 篇 + 极少量探索

### ★★★☆☆ #5. **Audio Reasoning + AIGC Generation**（音频推理 + AIGC 式生成）

**Priority Score：7.6 / 10**

- **AIGC 匹配度**：★★★★（文本 CoT + AIGC 已成熟，音频未迁移）
- **团队互补度**：★★★（与 duplex ALM 中度互补）
- **2026 行业信号**：★★★★★（Audio-DeepThinker, Audio-Cogito 已开路，但与 AIGC 结合仍空白）
- **痛点真实度**：★★★（音频任务复杂推理需求正在浮现）
- **复杂度合理度**：★★（reasoning + generation 联合训练复杂）

**Two-sentence Pitch**：
> 2026 年的 Audio-DeepThinker / Audio-Cogito 把 reasoning 引入 LALM，但 reasoning 的终点是"答案文本"，而非"音频内容"——这意味着复杂音频创作仍需用户自己动手。
> 我们让 LALM 在推理链中**生成中间音频 token**（多模态 CoT），最终输出完整音频——把"我想做一个有雨声背景的、节奏舒缓的钢琴曲"直接转化为完整音乐作品。

**2-Week Pilot**：
1. Week 1：在 MusicGen / AudioLDM 上探索 "chain-of-audio-token"——把生成过程拆为多步，每步生成 token 片段
2. Week 2：与 reasoning LALM（Audio-DeepThinker 思路）做联合微调
3. **可交付物**：一个 reasoning-audio generation demo

**Reference 借鉴**：
- 文本 + 视觉：Visual CoT, MM-CoT
- 音频 reasoning：Audio-DeepThinker, Audio-Cogito
- AIGC + reasoning：Thinking Diffusion, R1-style 扩散

## 备选 5 个（如果 Top 5 资源冲突）

### 备选 A. **Audio Inpainting / Outpainting**（音频补绘 / 外绘）
- **痛点**：损坏音频修复（电话噪音、老录音修复）、无缝延长背景音
- **AIGC 匹配度**：★★★★★（图像 inpainting 是 AIGC 经典）
- **优先级**：7.2 / 10
- **2-Week Pilot**：用 latent diffusion 实现 audio inpainting；在 MUSDB18 / 真实电话录音上测修复质量

### 备选 B. **Audio IP-Adapter / Style Reference**（音频风格参考生成）
- **痛点**：用 reference audio 提取风格，跨音色生成新音频
- **AIGC 匹配度**：★★★★（图像 IP-Adapter 是经典）
- **优先级**：7.0 / 10
- **2-Week Pilot**：在 codec latent 上做 reference embedding → 风格迁移

### 备选 C. **Diffusion Audio Codec**（扩散式神经音频 codec）
- **痛点**：现有 RVQ codec 离散不可编辑 → 用 diffusion 替代
- **AIGC 匹配度**：★★★★★
- **优先级**：6.8 / 10
- **2-Week Pilot**：基于 DAC / SoundStream 改造，第一版连续 latent + diffusion decoder

### 备选 D. **Audio for Embodied Agents**（具身智能的音频能力）
- **痛点**：具身 agent 视觉强、音频弱；2026 仅 1 篇
- **优先级**：6.5 / 10
- **2-Week Pilot**：选一个具身任务（navigation / manipulation），加入 audio branch

### 备选 E. **Spatial Audio Generation**（空间音频生成）
- **痛点**：ambisonic / HRTF 个性化生成是 niche 但 high-value
- **优先级**：6.0 / 10
- **2-Week Pilot**：基于 SoundStream + 空间编码器，生成首版 ambisonic

## 推荐策略建议

### 与团队现有方向的关系

```
       你的差异化方向        团队已有
            ↓                  ↓
        audio latent editing
        audio watermarking        duplex ALM
        audio diffusion streaming  ← 直接互补：duplex 需低延迟 TTS
        audio agent               ← 直接互补：LALM 之上的 orchestration 层
        audio reasoning + AIGC    ← 部分重叠：Audio-DeepThinker 思路
        
                              music generation
                              ← 间接互补：音乐生成 + 编辑 + 检索 = 完整 audio toolchain
```

### 优先级选择的两条路径

**路径 A：差异化优先（推荐）**
- 主做：#1 Audio Latent Editing + #2 Audio Watermarking
- 不重叠 duplex / music，论文可单独形成体系
- 适合：想快速建立独立 identity

**路径 B：协同优先**
- 主做：#3 Streaming Diffusion + #4 Audio Agent
- 与 duplex ALM 团队深度合作（共用 LALM 基础）
- 适合：想利用团队资源放大影响力
