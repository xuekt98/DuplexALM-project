## 一、Diverge Phase：5 框架并行生成候选

### 框架 F3：Tension Hunting（音频领域的核心 tension）

从 2026 论文里观察到 8 个核心 tension：

| Tension | 已有 SOTA 例子 | 机会 |
|---|---|---|
| **Latency ↔ Quality** | SwiftAudio / AudioX-Turbo 已做 1-step distillation | **streaming + causal + chunk-consistent** 仍未解 |
| **Comprehension ↔ Generation** | Audio-DeepThinker / Audio-Cogito reasoning 终点是文本 | **reasoning → audio generation** 仍 niche |
| **Modality Isolation ↔ Modality Fusion** | Seedance 2.0 统一多模态，AVENUE 评测 | **多模态 where audio 是 first-class** |
| **Real-time ↔ Reasoning** | StreamAV-Bench 是 audio-visual | **real-time audio reasoning** 未饱和 |
| **General ↔ Specific** | CosyEdit 通用、SpeechEditBench 评测 | **vertical-specific audio editing agent** |
| **Streaming ↔ Batch** | TontaubeV1 streaming TTS | **batch-quality streaming** 仍 niche |
| **Editing ↔ Generation** | MMAE benchmark 已建立 | **editing-driven generation**（用户意图先编辑后生成） |
| **Safety ↔ Capability** | AIGC detection 已开路 | **proactive safety in generation pipeline** |

### 框架 F4：Cross-Pollination（用 AIGC 经验跨界）

从 AIGC / 视觉成熟思路 → 音频未落地：

| AIGC / 视觉成熟 | 音频版本状态 | 机会 |
|---|---|---|
| **ControlNet（结构化控制）** | FreeSonic, DirectAudioEdit, Bagpiper-Edit 等已有 | **ControlNet for non-speech/non-music**（SFX 场景）|
| **IP-Adapter（reference 风格）** | voice conversion 已有，AdaTT / Polyphonia | **IP-Adapter for SFX / Foley** |
| **DragGAN（拖拽式编辑）** | 0 篇 | **Audio DragGAN for spatial audio** |
| **SDEdit（diffusion 局部编辑）** | MMAE 评测已建立 | **SDEdit for general audio** |
| **Inpainting（局部重绘）** | Diffusion-based audio inpainting 自 2022 | **已被做** |
| **Multi-ControlNet（多条件）** | FreeSonic 部分支持 | **多模态 control audio**（text + visual + audio） |
| **Reward model / RLHF** | TuneJury 在 text-to-music | **RL for audio reasoning** |
| **Latent diffusion** | Stable Audio, AudioLDM 2 | **已被做** |
| **Diffusion + autoregressive hybrid** | HybridCodec, DLLM-TTS | **已被做** |

### 框架 F5：What Changed（2026 改变的事）

| Change | Implication |
|---|---|
| **LALM 引入 reasoning** (Audio-DeepThinker / Audio-Cogito) | audio 任务变复杂，单步 LALM 不够 |
| **Audio-Visual 统一模型** (Seedance 2.0, VISA) | audio 与 video 绑定成趋势 |
| **AIGC 安全监管** (VoxENES 2026, Multi2AV-Safety) | 安全从检测转向预防 |
| **Streaming benchmark** (StreamAV-Bench) | streaming 是核心指标 |
| **Smart glasses** (SLT 2026 Challenge) | 第一视角 audio 崛起 |
| **Codec-integrated watermark** (WMCodec) | watermark 必须嵌入 codec 才鲁棒 |
| **Modality decoupling detection** (AIGC detection) | "cross-modal inconsistency" 假设被否定 |
| **Audio editing survey** (Pan et al.) | 领域被认可，但具体方法仍散乱 |

### 框架 F6：Failure Analysis（已知 SOTA 在哪里失败）

| 已知方法 | 已知失败模式 | 机会 |
|---|---|---|
| **LALM 推理** | ADQA 显示 LALM 不一定真用音频（silent-audio probing 失败） | **Audio-Dependency Verification Framework** |
| **Watermarking** | codec stress 后失效 (Clean Accuracy Does Not Guarantee Provenance) | **Codec-Robust Watermark Framework** |
| **Streaming diffusion** | 跨 chunk 音色 / 韵律跳变 | **Chunk-Consistent Audio Distillation** |
| **Reasoning + generation** | reasoning 可 hallucinate 内容 | **Reasoning-Aware Generation Verification** |
| **Audio agent** | tool 调用错误、循环调用 | **Audio Agent Failure Analysis** |
| **Audio inpainting** | 在强噪声下失败 | **已有方法** |
| **Spatial audio generation** | 与视频时间对齐失败 | **Audio-Visual Spatial Consistency** |
| **Voice cloning** | 跨语言 speaker identity 丢失 | **IWSLT 2026 已开路** |

### 框架 F8：Stakeholder Rotation（哪些 stakeholder 被忽视）

| Stakeholder | 痛点 | 现有方案 |
|---|---|---|
| **SFX 设计师 / 音效师** | 缺乏直观的音效编辑工具 | Audacity / Pro Tools 太原始 |
| **AR/VR 沉浸式内容创作者** | 缺乏空间音频编辑工具 | Specialized 但 niche |
| **游戏开发者** | 缺乏程序化生成 + 编辑的 audio 工作流 | Wwise 太专业 |
| **Smart glasses 开发者** | 缺乏第一视角 audio 模型 | SLT 2026 起步 |
| **Audio 数据策划师** | 缺乏自动数据清洗 / 标注工具 | 仅 Whisper 等 |
| **Audio 安全性审查员** | 缺乏 AIGC 检测 + 来源追溯 | VoxENES / ESDD2 已起步 |
| **Music producer** | 缺乏 AIGC 音乐编辑 + 引用追溯 | 已有但分散 |
| **AIGC 内容创作者** | 缺乏 audio 部分的可控生成 | Vorch-Streamer / Seedance 2.0 起步 |

## 四、Refine Phase：Top 5 + Two-Sentence Pitch + 2-Week Pilot

### ★★★★★ Top 1: Audio Data Curation Agent

**Score 19/20** — AIGC 经验最匹配 + 工程可行

**两句话 Pitch**：
> 当前 audio 数据集策划高度依赖人工——音频数据稀缺（特别是版权音乐、SFX、长音频），而 audio 模型训练对数据规模极敏感。
> 我们构建 **Audio Data Curation Agent**——以 LALM 为大脑，自动执行"下载候选 → ASR / 标注 → 去重 → 质量评分 → 去噪 → 入库"等步骤，让任何人都能在数小时内策划一个高质量的特定领域 audio 数据集。

**AIGC 经验匹配度**：★★★★★（data curation pipeline 是 AIGC 经典）
**团队互补度**：★★★★（与 duplex ALM / music gen 都有接口——它们都需要更多数据）

**2-Week Pilot**：
- Week 1：定义 5 个 audio data curation tools（ASR, music tagging, SFX classifier, near-dup detection, MOS prediction）
- Week 1：在 LALM 上做 SFT 让它学会 tool calling
- Week 2：选一个 specific 任务（如"为 speech repair 收集 100h 数据"），让 agent 跑 24h，统计可达成的数据规模和质量

---

### ★★★★★ Top 2: Audio Editing Agent

**Score 19/20** — 高 AIGC 匹配 + 高用户价值

**两句话 Pitch**：
> 当前 audio 编辑工具（Audacity、Pro Tools）需要专业技能，而 AIGC 让"用自然语言编辑音频"成为可能——但**当前 audio editing 仍需要用户一步步操作**。
> 我们构建 **Audio Editing Agent**——把 "把这首钢琴曲的第 1:30 改成忧郁的"、"把这段对话的背景噪音去掉" 等自然语言请求转换为 multi-step audio editing tool 调用，让音频编辑像跟音乐助手对话一样简单。

**AIGC 经验匹配度**：★★★★★（agent + editing 都是 AIGC 经典）
**团队互补度**：★★★★（与 duplex ALM 团队共享 LALM）

**2-Week Pilot**：
- Week 1：定义 5-10 个 audio editing tools（inpaint, pitch shift, style transfer, denoise, separation, generation）
- Week 1：在 LALM 上做 SFT
- Week 2：在 20 个 complex editing task 上测试 agent 成功率

---

### ★★★★ Top 3: SFX AIGC Pipeline (General Audio Generation + Editing)

**Score 18/20** — 直接对应 AIGC 经验 + 限定 niche

**两句话 Pitch**：
> 当前 AIGC 音频生成（AudioLDM / Stable Audio）能做"输入文本 → 输出音频"，但**生成的音频经常需要细调**（"这段雨声再密一点"），用户只能重新生成。
> 我们把 Stable Diffusion 的 SDEdit 思路迁移到 general audio（非 speech / 非 music）——先生成粗略音频，再基于用户反馈做 latent-space 局部编辑，**让"边生成边精修"成为可能**。

**AIGC 经验匹配度**：★★★★★（SDEdit / img2img 是 AIGC 经典）
**团队互补度**：★★★★★（与 music gen 不冲突——聚焦 SFX / ambient / Foley）

**2-Week Pilot**：
- Week 1：用 AudioLDM 2 做 SFX generation baseline
- Week 1：实现 SDEdit-style latent-space editing
- Week 2：在 30 个 user-requested editing scenarios 上测质量

---

### ★★★★ Top 4: Audio-Dependency Verification Framework

**Score 18/20** — 解决 ADQA 问题 + 与团队 LALM 强相关

**两句话 Pitch**：
> DCASE 2026 Task 5 揭示 LALM **不一定真用音频**——很多模型即使静音输入也能给出看似合理的答案，这意味着现有 LALM benchmark 报告的"音频理解能力"可能被严重高估。
> 我们构建 **Audio-Dependency Verification Framework**——对每个 LALM benchmark 自动生成 silent-audio probing + per-option perplexity + LLM commonsense check + human review pipeline，**让"LALM 是否真的用了音频"成为可验证的事实**。

**AIGC 经验匹配度**：★★★★（eval framework 是 AIGC 经典）
**团队互补度**：★★★★★（直接服务于 duplex ALM 团队的 LALM）

**2-Week Pilot**：
- Week 1：实现 silent-audio probing + per-option perplexity checker（基于 DCASE Task 5 ADF pipeline）
- Week 1：在 3 个 LALM benchmark（MMAE / AudioBench / AIR-Bench）上测试
- Week 2：发布 framework + 一份 "LALM benchmarks 音频依赖审计"

---

### ★★★★ Top 5: Smart Glasses First-Person Audio Agent

**Score 18/20** — 强 2026 趋势 + 与团队契合

**两句话 Pitch**：
> SLT 2026 SmartGlasses Challenge 揭示**第一视角音频**是 2026 趋势——但现有 challenge 聚焦 ASR / TSA-ASR，**未覆盖"agent"能力**。
> 我们构建 **Smart Glasses First-Person Audio Agent**——以 LALM 为大脑，把 first-person ASR + sound classification + scene description + tool calling 联合起来，让智能眼镜能"听见世界并主动响应"。

**AIGC 经验匹配度**：★★★（agent 是 AIGC 经典，但 smart glasses 是新硬件）
**团队互补度**：★★★★★（与 duplex ALM 团队极契合——都关心实时第一视角音频）

**2-Week Pilot**：
- Week 1：基于现有 SLT 2026 数据集扩展 agent 任务（从 ASR 到 ASR + tool use）
- Week 1：在 LALM 上做 SFT
- Week 2：定义 20 个 first-person audio tasks（"听到门铃声，调用开锁接口"等）测 agent 成功率
