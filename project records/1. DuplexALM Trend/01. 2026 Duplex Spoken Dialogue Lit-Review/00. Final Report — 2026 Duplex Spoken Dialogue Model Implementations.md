## 摘要（Abstract）

2026 年的 **Duplex Spoken Dialogue Model**（全双工口语对话模型）研究呈现**爆发式增长**：本文 2026-09 检索 arXiv，**79 篇严格相关论文**（标题必须包含 full-duplex / duplex / barge-in / turn-taking 等核心术语），其中 **2026 年就占 73 篇**，2025 年 5 篇，更早 1 篇。**这是 2024 年 Moshi 开山后两年内的快速扩张**，从单一架构（Moshi 4-stream interleaved token）演变为多种技术路线（cascaded ASR-LLM-TTS、native duplex LLM、modular dual-system、agentic duplex）。

## 3. 技术路线分类

### 3.1 架构范式

| 路线 | 代表 | 优缺点 |
|---|---|---|
| **Native duplex LLM**（单一自回归） | Moshi (2410), BayLing-Duplex (2606.14528), PersonaPlex (2602.06053) | 端到端、低延迟，但需大容量 |
| **Cascaded ASR-LLM-TTS** | DuplexCascade (2603.09180), FireRedChat (2509.06502), Dziri Voicebot (2606.26003) | 模块化、易部署，但有 latency / error propagation |
| **Dual-system / modular** | SALMONN-duo (2609.34247), AdaptDuplex (2609.29217) | 解耦理解与生成、灵活 |
| **LLM as backend + speech frontend** | Context Spanning (2609.33443), Realtime-Venus (2609.13814v3) | 复用现有 LLM、扩展性好 |
| **Tool-augmented agentic** | APEX-Voice (2609.34973), NemotronLabs VoiceChat (2609.21967), Full-Duplex-Bench-v3 (2604.04847) | 接入工具链、支持复杂 agent 任务 |

## 6. 关键趋势

1. **从单系统到 agentic**：2024-2025 大部分是 perception-and-response 系统，2026 大量引入 **tool use、planning、multi-step reasoning**
2. **从 cascade 到 native duplex**：Moshi (native) vs BayLing-Duplex vs DuplexCascade (cascade) 三种范式并存
3. **评测标准化**：HumDial Challenge、M3-DuplexBench 等让评测可比
4. **多模态 + multi-party**：从 1-on-1 扩展到 multi-party、含 facial / embodied（Integrating Facial Generation, MIRA）
5. **角色 + 个性化**：PersonaPlex、PersonaKit、CharDuplex 推动角色可控生成
6. **工业开源化**：Qwen-Audio-3.1-Realtime（阿里）、NemotronLabs VoiceChat（NVIDIA）、Realtime-Venus、Moshi（Kyutai）等开源模型涌现
