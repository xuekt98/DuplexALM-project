## 摘要

v3 方案以 **Multi-Faceted Interactivity Alignment (MFIA)** 的"4 canonical axes"为核心架构，将 QwenOmni-3 的 3-channel 输出与 axes 对齐：
- **4 axes**: pause handling / turn-taking / backchanneling / user interruption
- **1 anchor reward**: LLM judge 防 semantic degradation
- **每 axis 用不同 RL 算法**：Pause (DPO) / Turn-taking (GRPO+ASP) / Backchanneling (Conditional DPO) / Interruption (PG with FSM)
- 训练分 3 阶段：Pre-training → SFT → Multi-Axis RL（axis-specific）

## 论文核心洞察（MFIA）

**Title**: Multi-Faceted Interactivity Alignment in Full-Duplex Speech Models (2606.11167v2, 2026-06-09)
**作者团队**：Kyutai 等
**核心洞察**：

> "现有模型仅做 token-level likelihood maximization，**未直接优化 interaction-level behaviors**——导致 interactivity issues (excessive silence, ill-timed turn-taking)"
>
> "现有 RL 方法只针对**有限 axes**——我们提出 post-training alignment，**comprehensively** 优化**4 canonical axes**"

**4 canonical axes**：

| Axis | 含义 | 失败模式 |
|---|---|---|
| **Pause handling** | 沉默时长控制 | excessive silence |
| **Turn-taking** | turn-end → first speech latency | ill-timed response |
| **Backchanneling** | 副语言（"嗯" "对的"）时机 | missing / wrong position |
| **User interruption** | barge-in 响应质量 | silence / overlap |

**+ 第 5 个**：LLM-based reward for response quality（**anchor reward** 防 reward hacking）

**已验证**：在 Moshi 和 PersonaPlex 上都 work → 模型无关

### 2.2 4-Axes Head 设计

```python
import torch
import torch.nn as nn

class AxisHead(nn.Module):
    """Base class for 4-axis heads"""
    def __init__(self, hidden_dim, output_dim):
        super().__init__()
        self.proj = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, output_dim)
        )

class PauseHandlingHead(AxisHead):
    """Axis 1: Pause handling — 二元 speak/silence decision"""
    def __init__(self, hidden_dim):
        super().__init__(hidden_dim, 2)  # binary: speak vs silence
    
    def forward(self, h):
        logits = self.proj(h)
        return torch.softmax(logits, dim=-1)  # (B, T, 2)

class TurnTakingHead(AxisHead):
    """Axis 2: Turn-taking — latency prediction"""
    def __init__(self, hidden_dim):
        super().__init__(hidden_dim, 1)  # predicted latency in ms
    
    def forward(self, h):
        latency_ms = torch.relu(self.proj(h))  # (B, T, 1)
        return latency_ms

class BackchannelHead(AxisHead):
    """Axis 3: Backchanneling — conditional binary on context"""
    def __init__(self, hidden_dim):
        super().__init__(hidden_dim, 2)  # binary: trigger backchannel or not
        # 额外输入：对方是否在说话（VAD 信号）
        self.context_proj = nn.Linear(1, hidden_dim)
    
    def forward(self, h, vad_signal):
        # vad_signal: (B, T, 1) - 对方说话状态
        context = self.context_proj(vad_signal)
        combined = h + context
        logits = self.proj(combined)
        return torch.softmax(logits, dim=-1)

class InterruptionHead(AxisHead):
    """Axis 4: User interruption — FSM-based decision"""
    def __init__(self, hidden_dim, n_states=5):
        # FSM 状态: LISTENING, ABOUT_TO_SPEAK, SPEAKING, INTERRUPTED, YIELDED
        super().__init__(hidden_dim, n_states)
        # FSM transition logic
    
    def forward(self, h, current_state):
        state_logits = self.proj(h)
        # 输出下一个 state
        next_state = torch.argmax(state_logits, dim=-1)
        return next_state, state_logits
```

### 2.3 完整 Forward Pass

```python
class MultiFacetedDuplexALM(nn.Module):
    """基于 QwenOmni-3 + MFIA 4-axes"""
    def __init__(self, qwen_backbone, audio_encoder, speech_decoder):
        super().__init__()
        self.audio_encoder = audio_encoder
        self.qwen = qwen_backbone
        self.speech_decoder = speech_decoder
        
        # 4 axes heads
        hidden_dim = qwen_backbone.config.hidden_size
        self.pause_head = PauseHandlingHead(hidden_dim)
        self.turn_taking_head = TurnTakingHead(hidden_dim)
        self.backchannel_head = BackchannelHead(hidden_dim)
        self.interruption_head = InterruptionHead(hidden_dim)
    
    def forward(self, user_audio, user_text=None, history=None):
        # 1. Audio encoding
        user_emb = self.audio_encoder(user_audio)  # (B, T_audio, D)
        
        # 2. Multimodal fusion
        if user_text:
            text_emb = self.qwen.embed_tokens(user_text)
            input_emb = torch.cat([user_emb, text_emb], dim=-2)
        else:
            input_emb = user_emb
        
        # 3. Qwen3 backbone
        hidden = self.qwen(inputs_embeds=input_emb).last_hidden_state
        
        # 4. 4 axes heads (parallel)
        pause_decision = self.pause_head(hidden)         # (B, T, 2)
        tt_latency = self.turn_taking_head(hidden)      # (B, T, 1)
        bc_trigger = self.backchannel_head(hidden, vad_signal)  # (B, T, 2)
        fsm_state, fsm_logits = self.interruption_head(hidden, current_state)
        
        # 5. Speech decoder
        assistant_audio = self.speech_decoder(hidden)
        
        return {
            'assistant_audio': assistant_audio,
            'pause_decision': pause_decision,    # Axis 1
            'tt_latency': tt_latency,            # Axis 2
            'bc_trigger': bc_trigger,            # Axis 3
            'fsm_state': fsm_state,              # Axis 4
            'fsm_logits': fsm_logits,
            'hidden': hidden,
        }
```

def stage2a_pause_dpo(model, pause_pairs, n_hours=48):
    """Pause handling: DPO on binary speak/silence pairs"""
    
    for pair_batch in pause_pairs:
        # pair_batch: list of {chosen_silence_duration, rejected_silence_duration}
        chosen_audio_emb = model.audio_encoder(pair_batch['chosen_audio'])
        rejected_audio_emb = model.audio_encoder(pair_batch['rejected_audio'])
        
        chosen_logits = model.pause_head(model.qwen(chosen_audio_emb))
        rejected_logits = model.pause_head(model.qwen(rejected_audio_emb))
        
        # DPO loss: 让 chosen logp > rejected logp
        chosen_logp = torch.log(chosen_logits[:, -1, 1] + 1e-8)  # "speak" prob
        rejected_logp = torch.log(rejected_logits[:, -1, 1] + 1e-8)

        ref_chosen_logp = ...
        ref_rejected_logp = ...

```python
def stage2b_turn_taking_grpo(model, turn_taking_groups, n_hours=48):
    """Turn-taking latency: GRPO optimizes latency under quality constraint"""
    
    for group in turn_taking_groups:  # group size = 8
        # 每个 group: 8 个不同的 response latency choices
        group_rewards = []
        for sample in group:
            output = model(sample['user_audio'])
            latency = output['tt_latency']  # (B, T, 1)
            
            # Reward: 快但不能太短（避免打断）
            if 100 < latency < 800:  # ms
                reward = 1.0 - (latency - 400).abs() / 400  # peak at 400ms
            else:
                reward = -1.0
            
            # Semantic anchor (从 LLM judge 来)
            semantic_reward = llm_judge(sample['response_text'])
            
            total_reward = 0.7 * reward + 0.3 * semantic_reward
            group_rewards.append(total_reward)
        
        # GRPO: group-relative advantage
        advantages = (group_rewards - group_rewards.mean()) / (group_rewards.std() + 1e-8)
        
        # Policy gradient loss
        log_probs = compute_log_probability(model, group)
        loss = -(log_probs * advantages).mean()
        loss.backward()
```

```python
def stage2c_backchannel_dpo(model, backchannel_pairs, n_hours=36):
    """Backchanneling: Conditional DPO based on VAD state"""
    
    for batch in backchannel_pairs:
        # batch includes: vad_state (对方是否在说话), chosen_backchannel_audio, rejected_no_audio
        vad_signal = batch['vad_state']  # (B, T, 1)
        
        chosen_emb = model.audio_encoder(batch['chosen_audio'])
        rejected_emb = model.audio_encoder(batch['rejected_audio'])
        
        chosen_bc = model.backchannel_head(model.qwen(chosen_emb), vad_signal)
        rejected_bc = model.backchannel_head(model.qwen(rejected_emb), vad_signal)
        
        # Conditional DPO: chosen 在对方说话时 backchannel，rejected 不 backchannel
        chosen_logp = torch.log(chosen_bc[:, -1, 1] + 1e-8)  # "trigger backchannel"
        rejected_logp = torch.log(rejected_bc[:, -1, 1] + 1e-8)
        
        dpo_loss = -F.logsigmoid(0.1 * (chosen_logp - rejected_logp)).mean()
        dpo_loss.backward()
```

#### **Stage 2d: Interruption via Policy Gradient + FSM**

```python
def stage2d_interruption_pg(model, interruption_scenarios, n_hours=36):
    """User interruption: PG with FSM state transitions"""
    
    for scenario in interruption_scenarios:
        # scenario: {user_audio, barge_in_position, expected_model_behavior}
        output = model(scenario['user_audio'])
        
        # FSM state transitions
        # 0=LISTENING, 1=ABOUT_TO_SPEAK, 2=SPEAKING, 3=INTERRUPTED, 4=YIELDED
        state_seq = []
        for t in range(output['fsm_logits'].size(1)):
            state_seq.append(output['fsm_state'][:, t])
        
        # Reward: 正确的 FSM transition
        target_seq = scenario['expected_fsm_states']
        state_loss = F.cross_entropy(
            output['fsm_logits'].reshape(-1, 5),
            torch.tensor(target_seq).flatten()
        )
        
        # Reward: 是否 graceful yield / immediate response
        fsm_reward = compute_fsm_reward(state_seq, scenario)
        
        # PG loss
        log_probs = compute_fsm_log_probs(output['fsm_logits'])
        pg_loss = -(log_probs * fsm_reward).mean()
        
        # Combined loss
        loss = state_loss + 0.5 * pg_loss
        loss.backward()
```

#### **Stage 2e (concurrent): LLM Judge Anchor**

```python
class LLMJudgeReward(nn.Module):
    """5th reward: LLM judge for semantic quality (anchor)"""
    def __init__(self, judge_model='qwen2.5-72b'):
        self.judge = judge_model
    
    def compute(self, response_text, context):
        prompt = f"""Rate the quality of this response on a 0-1 scale.
        Context: {context}
        Response: {response_text}
        Consider: relevance, coherence, helpfulness, naturalness.
        Score:"""
        return self.judge.generate(prompt)  # 0-1

def stage2e_anchor_reward(model, batches, n_hours=continuous):
    """Anchor reward runs in parallel with all axis RL stages"""
    for batch in batches:
        output = model(batch)
        
        # LLM judge for semantic quality
        semantic_score = llm_judge(output['text_response'], batch['context'])
        
        # 如果 semantic_score < 0.6，降低 axes reward 权重
        # 否则按正常 reward 训练
        axes_weight = max(0.0, (semantic_score - 0.4) / 0.6)
        
        # Apply axes_weight to all axis RL updates
        for axis_loss in batch['axis_losses']:
            weighted_loss = axes_weight * axis_loss
            weighted_loss.backward(retain_graph=True)
```

## 验证清单（按 F10 Explain-It Test）

✅ **Two-sentence pitch**（清晰）：
- 当前 full-duplex ALM 在 4 个 interactivity axes 上存在失败模式（pause 过长 / turn-taking 不准 / backchannel 错位 / barge-in 响应差）
- 我们基于 MFIA 论文设计 4 axes heads + axis-specific RL（DPO / GRPO / Conditional DPO / PG with FSM）+ LLM Judge anchor 防 semantic 退化

✅ **Problem-first check**：MFIA 论文已在 Moshi / PersonaPlex 验证 4 axes 失败模式真实

✅ **Approach justified**：每个 axis 的 RL 算法选择有明确理由

✅ **Stakeholder clear**：QwenOmni-3 团队 + 智能音箱厂商

✅ **3 个 concrete experiments**：
1. Stage 2a Pause DPO：在 Switchboard pause test 上验证 KL divergence
2. Stage 2b Turn-Taking GRPO：在 DuplexBench 上验证 latency p50/p95
3. Stage 2e Anchor：验证 axes 训练后 semantic 退化 < 5%

✅ **2-Week Pilot**：
- Week 1：Stage 2a (Pause DPO) + Stage 2b (Turn-Taking GRPO) —— 最容易的两个 axes
- Week 2：Stage 2c (Backchannel DPO) + Stage 2e (LLM Judge) —— 验证 semantic 保持

✅ **Strongest objection response**：
- 反对：4 axes 分别训练工程量大、reward 难协调
- 回应：Stage 2e LLM Judge 自动调整 axes_weight；MFIA 论文已证明可迁移
