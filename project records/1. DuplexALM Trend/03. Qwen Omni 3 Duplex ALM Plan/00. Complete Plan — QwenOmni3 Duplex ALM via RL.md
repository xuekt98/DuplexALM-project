## 摘要：方法概述

基于 QwenOmni-3 backbone 构建 end-to-end FullDuplex ALM，训练分 **3 阶段**（Pre-training → SFT → Multi-Stage RL），核心创新是 **3-Channel Architecture**（user audio + assistant audio + action text）+ **Action Space Projection**（ASPIRin 思路）+ **Multi-Reward RLAIF**（semantic + audio + turn-taking + tool-use）+ **Decoupled GRPO**（when-to-speak / what-to-say 分离优化）。

## Part 2：模型整体结构

### 2.1 核心架构：3-Channel Duplex ALM（基于 DuplexSLA + ASPIRin）

```
┌─────────────────────────────────────────────────────────┐
│                  QwenOmni-3 Backbone                      │
│  ┌──────────────────┐   ┌──────────────────┐             │
│  │  Audio Encoder   │   │   Text Tokenizer │             │
│  │  (CNN/Trans)     │   │   (BPE/SentenceP) │             │
│  └────────┬─────────┘   └────────┬─────────┘             │
│           ↓                       ↓                       │
│  ┌─────────────────────────────────────────────────┐     │
│  │      Shared Multimodal LLM (Qwen3 style)       │     │
│  │      - Audio tokens + Text tokens as input      │     │
│  │      - 3 output heads:                          │     │
│  │        ① Assistant audio tokens                 │     │
│  │        ② Text response tokens                    │     │
│  │        ③ Action tokens (speak/silence/tool)     │     │
│  └─────────────────────────────────────────────────┘     │
│           ↓                       ↓                       │
│  ┌──────────────────┐   ┌──────────────────┐             │
│  │  Speech Decoder  │   │  Action Decoder   │             │
│  │  (Causal Conv)   │   │  (Binary + Tool)  │             │
│  └──────────────────┘   └──────────────────┘             │
└─────────────────────────────────────────────────────────┘
```

### 2.2 关键创新模块

#### **A. 3-Channel Input/Output**（受 DuplexSLA 启发）

```
Channels (160ms chunked):
  Channel 1: User Audio Stream (continuous)
  Channel 2: Assistant Audio Tokens (discrete)
  Channel 3: Action Stream (speak/silence/tool-call, rate-limited to ~10/sec)
```

#### **B. Action Space Projection**（受 ASPIRin 启发）

```python
class ActionSpaceProjector(nn.Module):
    """把 vocab 投影到 binary (speak/silence) 状态空间"""
    def __init__(self, vocab_size, hidden_dim):
        self.active_proj = nn.Linear(hidden_dim, hidden_dim)
        self.inactive_proj = nn.Linear(hidden_dim, hidden_dim)
    
    def forward(self, hidden_states):
        # 投影到 active speech / inactive silence 二元状态
        active_logits = self.active_proj(hidden_states)
        inactive_logits = self.inactive_proj(hidden_states)
        return torch.cat([inactive_logits, active_logits], dim=-1)
```

#### **C. Turn-Taking Controller**（独立模块可选）

```
User Audio → Encoder → Turn-Taking Decision Module
                          ↓
                    {speak | silence | backchannel}
```

### 2.3 完整 forward pass

```python
def forward(user_audio, user_text=None, prev_assistant_audio=None, 
            prev_assistant_text=None, history=None):
    # 1. Audio encoding (streaming, 160ms chunks)
    user_audio_emb = self.audio_encoder(user_audio)  # (B, T_user, D)
    
    # 2. Text encoding (optional multimodal)
    user_text_emb = self.text_encoder(user_text) if user_text else None
    
    # 3. Multimodal fusion
    input_emb = torch.cat([user_audio_emb, user_text_emb], dim=-2)
    
    # 4. Qwen3 LLM backbone
    hidden = self.qwen_backbone(input_emb, history=history)
    
    # 5. Three output heads
    assistant_audio_logits = self.audio_head(hidden)      # Channel 2
    assistant_text_logits = self.text_head(hidden)        # Semantic response
    action_logits = self.action_head(hidden)             # Channel 3: turn/tool
    
    # 6. Action Space Projection for turn-taking RL
    action_decision = self.action_projector(action_logits)  # binary: speak/silence
    
    return {
        'assistant_audio': assistant_audio_logits,
        'assistant_text': assistant_text_logits,
        'action': action_decision,  # 用于 GRPO 训练
        'hidden': hidden  # 用于中间层损失
    }
```

### 2.4 模型规模建议

| 组件 | 参数量 | 依据 |
|---|---|---|
| Audio Encoder | ~200M | 16kHz → 160ms chunks，参考 Covo-Audio |
| Multimodal LLM Backbone | ~7B-13B | Qwen3-7B/14B 已有音频能力 |
| Speech Decoder | ~200M | causal Conv + vocoder |
| Action Projector | ~10M | 轻量级 |
| **Total** | **~7-14B** | 与 Covo-Audio (7B), Step-Audio-R1 相当 |

### 3.4 Stage 3：Multi-Stage RL（核心创新）

#### **Stage 3a: RLAIF with Multi-Reward**（基于 Optimizing Conv. Quality + WavAlign）

```python
class MultiRewardModel(nn.Module):
    """Multi-reward for duplex SDS"""
    def __init__(self):
        self.semantic_reward = SemanticReward()      # LLM judge
        self.audio_reward = AudioReward()              # Audio quality model
        self.emotion_reward = EmotionReward()          # Emotion consistency
        self.turn_taking_reward = TurnTakingReward()   # FCDR (Decoupling)
    
    def compute_reward(self, conversation):
        return {
            'semantic': self.semantic_reward(conversation),
            'audio': self.audio_reward(conversation),
            'emotion': self.emotion_reward(conversation),
            'turn_taking': self.turn_taking_reward(conversation),
        }

def stage3a_rlaif(model, preference_data, n_gpu=32, hours=30000):
    """Multi-reward RLAIF with turn-level preference sampling"""
    reward_model = MultiRewardModel()
    
    # 用 DPO objective（per-block log-prob aggregation）
    for batch in preference_data:
        # 每个 conversation → 多个 candidate → pairwise preferences
        rewards = reward_model.compute_reward(batch)
        
        # 联合优化所有 reward
        loss = compute_dpo_loss(
            model=model,
            batch=batch,
            rewards=rewards,
            aggregation='turn_level'  # 关键：turn-level preference sampling
        )
        loss.backward()
        optimizer.step()
```

#### **Stage 3b: GRPO with Action Space Projection**（核心创新 — 基于 ASPIRin）

```python
class ActionSpaceProjectedGRPO:
    """GRPO training with action space projection for turn-taking"""
    def __init__(self, model, action_projector):
        self.model = model
        self.action_projector = action_projector
    
    def compute_advantage(self, rewards):
        """GRPO: group-relative advantage"""
        mean_reward = rewards.mean(dim=-1, keepdim=True)
        std_reward = rewards.std(dim=-1, keepdim=True)
        return (rewards - mean_reward) / (std_reward + 1e-8)
    
    def step(self, batch):
        # 1. Forward with action projection
        output = self.model(batch)
        action_logits = output['action']  # (B, T, 2) - binary speak/silence
        
        # 2. Compute FCDR-style reward (Decoupling Conversational Dynamics)
        fcdr_reward = self.compute_fcdr_reward(
            action_logits=action_logits,
            behaviors=['turn_initiation', 'backchanneling', 
                      'yielding', 'pause_handling']
        )
        
        # 3. GRPO loss with rule-based rewards
        # 关键：把 timing 优化从 token 优化中分离
        log_probs = self.compute_action_log_probs(action_logits)
        advantages = self.compute_advantage(fcdr_reward)
        grpo_loss = -(log_probs * advantages).mean()
        
        # 4. 反向传播只更新 action 相关参数
        grpo_loss.backward()
        optimizer.step()
```

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| **Reward hacking**（SteerDuplex 已发现：模型可能学会 incomplete response 来通过 timing reward） | Multi-reward 联合优化 + human eval validation |
| **Semantic collapse**（raw-token RL 导致 repetition，ASPIRin 论文发现） | Action Space Projection 隔离 timing 优化 |
| **过拟合到用户数据** | 严格 PII filtering + DP review |
