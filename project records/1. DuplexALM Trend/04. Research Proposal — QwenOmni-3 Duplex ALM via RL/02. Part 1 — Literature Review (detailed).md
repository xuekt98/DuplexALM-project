## 2.1 全双工口语对话系统的范式演变

### 2.1.1 级联范式的三个结构性缺陷

口语对话系统的发展经历了从**级联（cascaded）到原生（native）**的范式转变。级联范式由 ASR → 文本对话模型 → TTS 三模块串接组成，turn-taking 由独立 VAD 模块强制切分。该架构存在三个结构性缺陷：
1. 模块串行导致秒级延迟（typical pipeline latency 1-3 秒）
2. 文本中间表示丢失 emotion、prosody、non-speech sounds 等非语义信息
3. VAD 强制半双工 turn 无法处理 barge-in、overlapping speech、interjections

### 2.1.2 原生范式：Moshi 的 4-stream interleaved token

**Moshi**（Défossez et al., 2024, arXiv:2410.00037）的**完整方法**：

**Cast spoken dialogue as speech-to-speech generation**：与级联范式不同，Moshi **不使用** VAD 或显式 turn segmentation——它把对话视为连续 speech-to-speech generation。

**具体架构**：
- Starting from a text language model backbone
- Generates speech as tokens from the residual quantizer of a neural audio codec
- Modeling separately its own speech and that of the user into parallel streams
- First predict **time-aligned text tokens** as a prefix to audio tokens（"Inner Monologue"）

**性能**：**160 ms theoretical / 200 ms practical first-audio-token latency**，开源：https://github.com/kyutai-labs/moshi

### 2.1.3 一个根本性缺陷：MFIA 的诊断

**MFIA**（Défossez et al., 2026a, arXiv:2606.11167v2）的诊断原文：

> "Current models are trained solely with supervised learning through token-level likelihood maximization, **which does not directly optimize interaction-level behaviors**, causing interactivity issues such as excessive silence and ill-timed turn-taking. Recent work has applied reinforcement learning (RL) to improve interactivity, but **existing methods address only a limited set of interactive behaviors in their rewards**."

**本研究核心动机**：RL 是直接优化交互行为的关键路径，但需要解决 multi-axis 优化问题。

## 2.2 用户指定的 4 篇核心参考论文：Methods in Depth

### 2.2.1 MFIA — Multi-Faceted Interactivity Alignment（核心方法）

**ArXiv ID**：2606.11167v2
**机构**：Kyutai（同一团队做 Moshi）

**Post-training alignment method**：

**Step 1: Four canonical axes of interactivity**

| Axis | 含义 |
|---|---|
| pause handling | 沉默时长控制 |
| turn-taking | turn-end → first token latency |
| backchanneling | 副语言时机（如 "嗯" "对"）|
| user interruption | barge-in 响应 |

**Step 2: Data extraction**
- 从 human conversation corpora 中**extract short audio segments**对应每 axis

**Step 3: Axis-specific reward functions**
- 每 axis 设计**专用的 reward function**

**Step 4: LLM-based anchor reward**（关键设计）
- **An extra LLM-based reward for response quality prevents semantic degradation**
- 在 SteerDuplex 中已观察到 reward hacking——模型可学到 incomplete response 通过 timing reward
- MFIA 用 anchor reward **主动防止**此问题

**Step 5: Post-training alignment application**
- Applied to Moshi and PersonaPlex
- Demonstrating consistent improvements in interactivity

### 2.2.2 DuplexSLA — Speech-Language-Action（完整架构）

**ArXiv ID**：2605.20755v2
**项目地址**：https://github.com/hyzhang24/DuplexSLA

**问题诊断原文**：
> "Existing duplex backbones still lack a native channel for in-conversation planning and tool calling, leaving real-time agentic behaviour either tied to turn boundaries or relegated to an external cascade."

**完整架构：Dual-stream Three-channel Formulation**

**3 个 channels**：
1. Continuous user audio channel
2. Discrete assistant audio channel
3. Rate-limited textual action channel

**关键设计细节**：

**Shared 160 ms chunk timeline**：三个 channels 在同一 160 ms 时钟上解码
- **all decoded jointly by a single backbone**
- listening、speaking、planning、tool calling **在同一个 160 ms 时钟上 unfold**

**两个核心能力**：

**Semantic-driven turn-taking control**（能力 1）
- interruption、pause、backchannel **全部在同一个 backbone 内处理**
- **不再依赖外部 semantic VAD**

**In-conversation planning + tool calling**（能力 2）
- Planning text + structured tool calls **emitted on action channel**
- **不阻塞 assistant audio**

**评估基准：DuplexSLA-Bench**
- 覆盖 pause、interrupt、backchannel turn-taking
- 3 种 styles of in-conversation tool calling

### 2.2.3 Cocktail-Talker — Turn Action GRPO（完整方法）

**ArXiv ID**：2607.27756v1

**问题诊断原文**：
> "Spoken dialog systems are typically designed for clean, dyadic interactions... Real-world social conversations, however, are often more ambiguous: multiple speakers may participate in the same conversation amid irrelevant speech and background noise. Each utterance may be directed to the assistant, addressed to another speaker, or completely irrelevant. In such settings, the assistant must decide not only what to say, but also whether to speak at all."

**完整方法：三个 Action Tokens**

| Token | 触发场景 |
|---|---|
| `<|respond|>` | 对话者对你说话，应该回应 |
| `<|listen|>` | 对话者之间互相说话，倾听即可 |
| `<|ignore|>` | 与你无关的对话，忽略 |

**Token 位置**：placed **before a response or silence**

**训练流程**：

**Step 1: Cocktail-DialogGen（LLM-driven data pipeline）**
- 模拟 realistic multi-speaker dialogs
- speaker roles across diverse social settings
- 用 LLM 模拟多 speaker 嘈杂场景

**Step 2: Supervised finetuning**
- 学习基本 action token 选择

**Step 3: Turn Action GRPO（RL 阶段）**
- 三个 action token 是 action space
- Reward 来自 **LLM-judged 多 speaker 场景理解**
- 优化 "是否要回应 + 对谁回应"

### 2.2.4 Decoupling Conversational Dynamics — DuplexPO（完整方法）

**ArXiv ID**：2607.07148v1

**核心论证原文**：
> "Such an intelligence-dynamics trade-off is not fundamental: conversational dynamics can instead be learned as a **separate real-time decision policy** from human dialogue data."

**完整方法：DuplexPO RL Framework**

**Step 1: Decoupling Principle**
- **Preserves** the semantic response capability of an instruction-tuned assistant
- **Optimizes** temporal interaction behavior **separately**

**Step 2: High-impact Windows Selection**
- Selected **high-impact windows from long human conversations**

**Step 3: Factorized Conversational Dynamics Reward (FCDR)**

FCDR 是 **fine-grained temporal credit assignment**，包含 4 个子 reward：

| FCDR Component | 含义 |
|---|---|
| turn initiation | 主动发起 turn 的能力 |
| backchanneling | 副语言时机 |
| yielding | 让出 turn 的能力 |
| regularized participation | 避免过度沉默或过度发言 |

**Step 4: RL 算法**
- **GRPO-style objective**

**关键实验结果**：
- substantially improves timely backchannels / smooth turn-taking / barge-in handling
- **同时保持 reasoning 与 instruction-following**（关键：不破坏语义）

## 2.3 其他相关 RL 论文：Methods in Depth

### 2.3.1 ASPIRin — Action Space Projection

**ArXiv ID**：2604.10065v1

**问题诊断原文**：
> "Optimizing temporal dynamics via standard raw-token reinforcement learning (RL) **degrades semantic quality**, causing **severe generative collapse and repetition**."

**完整方法**：

**核心 principle**：**explicitly decouples when to speak from what to say**

**Action Space Projection 的具体操作**：
- Maps the **text vocabulary into a coarse-grained binary state** (active speech vs. inactive silence)
- 不在 raw token space 优化 → 避免 repetition

**RL 算法**：
- **Group Relative Policy Optimization (GRPO)** with **rule-based rewards**
- 优化目标：**balance user interruption + response latency**

**行为覆盖**：
- turn-taking
- backchanneling
- pause handling

**关键结果（量化）**：
- **重复 n-gram 比例减少 50% 以上**
- **有效消除 degenerative repetition**（vs standard GRPO）

### 2.3.2 WavAlign — Modality-aware RL

**ArXiv ID**：2604.14932v1

**问题诊断原文**：
> "Sparse preference supervision interacts with dense speech generation under shared-parameter updates."

**完整方法**：

**核心 principle**：**modality-aware adaptive post-training**

**关键设计细节**：
1. **Constrains preference updates to the semantic channel**
2. **Acoustic behavior** 通过 **explicit anchoring** 改进
3. **Dynamically regulates mixture from rollout statistics** 避免 unreliable preference gradients

### 2.3.3 Dual-Axis Generative Reward Model

**ArXiv ID**：2604.14920v1

**问题诊断原文**：
> "Prevailing automated metrics for assessing interaction quality rely on superficial proxies... human evaluations, despite their richness, remain costly, inconsistent, and difficult to scale."

**完整方法**：

**Generative Reward Model**：
- Trained to understand complex interaction dynamics（使用 detailed taxonomy + annotated dataset）
- 输出**单 score + 分别的 semantic / timing 两个分数**

**关键价值**：
- **Dependable, instructive reward signal** suitable for online reinforcement learning

### 2.3.4 Optimizing Conv. Quality with RLAIF

**ArXiv ID**：2601.19063v1

**完整方法**：

**Multi-reward 框架**：
- semantic quality
- audio quality
- emotion consistency

**Turn-level preference sampling**：适配 blockwise duplex model 的 incremental decoding

**Per-block log-prob aggregation**：在 DPO objective 内聚合

### 2.3.5 Aligning SDM from User Interactions

**ArXiv ID**：2506.21463v1

**完整方法**：

**Dataset**：
- **15 万对偏好** from raw multi-turn speech conversations + AI feedback
- 针对 **temporal context variations** + linguistic content

### 2.3.6 SteerDuplex（reward hacking 警示）

**ArXiv ID**：2609.12623v1

**完整方法**：

**Steerability taxonomy**：text-based + audio-based

**Moshi-based** 全双工 speech model

**Two-stage RL with hybrid rewards**：
- **verifiable interaction checks**（timing / barge-in）
- **judge-based semantic feedback**（LLM judge）

**SteerBench**：390 spoken prompts + 1067 human-authored binary audio/text rubrics

**关键实验结果**：
- SFT 后 audio-steering 平均 pass rate **+44.5 pp** vs strongest open baseline
- **Source-clean interruption response** 72.5% → **82.5%**（+RL 后）
- **Synthetic pause barge-in** 26.5% → **9%**

**关键发现 — reward hacking 风险原文**：
> "Reward probes reveal **reward hacking through incomplete responses**."

**对本研究的核心警示**：**必须**用 anchor reward 防止 reward hacking。

### 2.3.7 Step-Audio-R1（reasoning RL）

**核心方法**：Modality-Grounded Reasoning Distillation (MGRD)
- 生成 audio-relevant reasoning chains
- **genuinely grounded in acoustic features**（不 hallucinating disconnected deliberations）

### 2.3.8 FLAIR — Latent Reasoning

**核心方法**：
- 在 user speaking phase **递归地在 latent embedding 空间中思考**
- **ELBO-based objective** 支持 supervised finetuning via teacher forcing

### 2.3.9 PersonaPlex（role + voice）

**核心方法**：
- Hybrid system prompt：role conditioning + voice cloning
- 合成 dataset
- 超越 SOTA duplex speech models 在 role adherence、speaker similarity、latency、naturalness

## 2.5 研究空白与本研究定位

综合以上文献，全双工口语对话模型的 RL 研究仍存在三个关键空白。

### 2.5.1 空白一：模型规模受限

**已有 RL 工作的最常用 base**：Moshi（约 7B）、PersonaPlex（约 7B）、SALMONN-omni（不到 10B）。**针对 30B 级开源全双工基础模型（如 QwenOmni-3 30B）的 RL 微调仍是空白**。

**QwenOmni-3 30B 的优势**：(1) 多模态理解能力强；(2) 已有 audio 适配基础；(3) 计算资源足以支撑 RL 训练。但其在全双工交互上的 RL 适配**尚未被系统研究**。

### 2.5.2 空白二：单一交互 axis 优化为主

已有 RL 工作往往聚焦单一 axis：ASPIRin（仅 timing）、Dual-Axis GRM（仅 semantic + timing）、Cocktail-Talker（仅 respond/listen/ignore）。

**Multi-Faceted Interactivity Alignment（MFIA）虽提出 4-axis 框架**（pause handling / turn-taking / backchanneling / user interruption），但**仅在 Moshi（~7B）与 PersonaPlex（~7B）上验证**，尚未在 30B 量级模型上验证其可扩展性。

### 2.5.3 空白三：缺乏稳定的"语义 vs 交互"权衡

- **ASPIRin** 已显示 raw-token RL 会导致 repetition
- **WavAlign** 提出 modality-aware RL（仅在 semantic channel 更新）
- **MFIA** 提出 LLM judge anchor reward
- **SteerDuplex** 发现 reward hacking 风险（模型可学到 incomplete response）

**这些权衡机制在 30B 量级模型上的效果与可扩展性仍未验证**。具体问题：
1. 在 30B 模型上，anchor reward 的权重应该如何调整？
2. 30B 模型是否更容易发生 reward hacking？
3. WavAlign 的 modality-aware 在大模型上是否依然有效？

### 2.5.4 本研究定位

针对上述空白，本研究（详见第 3 章）拟在 QwenOmni-3 30B 上：

1. **实现 MFIA 的 4-axis 框架**，但对每个 axis 选择最适合的 RL 算法：
   - **Pause Handling**：**DPO**（二元决策）
   - **Turn-Taking**：**GRPO + ASPIRin's Action Space Projection**
   - **Backchanneling**：**Conditional DPO**（基于对方是否在说话）
   - **Interruption**：**Policy Gradient + FSM state machine**

2. **保留 ASPIRin 的核心 insight**：Action Space Projection 把 vocab 投影到 binary state，**避免 raw-token RL 的 repetition**

3. **保留 MFIA 的 LLM Judge anchor**：防止 axes 训练导致 semantic collapse

4. **引入 WavAlign 的 modality-aware 思想**：RL 更新限制在 semantic channel，acoustic behavior 通过 explicit anchoring

5. **在统一 benchmark 上评估**：MMAE + DuplexBench + APEX-Voice + Cocktail-Talker Eval

本研究的核心贡献是**首次在 30B 量级全双工模型上系统实现并验证多轴交互对齐方法**，为工业级（30B+）全双工系统的 RL 训练提供可扩展的方法论。
