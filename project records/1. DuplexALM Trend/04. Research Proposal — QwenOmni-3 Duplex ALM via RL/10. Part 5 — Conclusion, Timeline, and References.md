## 6.1 Summary of the proposal

This proposal presents a method for training **QwenOmni-3 30B** as an end-to-end full-duplex spoken dialogue model with reinforcement learning, addressing the central challenge that existing full-duplex spoken dialogue systems are limited to 7B–10B scale while industrial deployment requires 30B-scale semantic capability.

The method integrates insights from five recent 2026 papers:
- **MFIA** (Défossez et al., 2026a) provides the 4-axis interactivity framework
- **DuplexSLA** (Zhang et al., 2026) provides the 3-channel architecture
- **ASPIRin** (Chen et al., 2026) provides the Action Space Projection preventing raw-token RL degeneration
- **WavAlign** (Wang et al., 2026) provides the modality-aware mask preventing acoustic degradation
- **Cocktail-Talker** (Xin et al., 2026) provides multi-speaker noisy training methodology

Each component addresses a specific failure mode that would otherwise prevent effective RL on a 30B-scale full-duplex model:

| Component | Failure mode addressed |
|---|---|
| MFIA's 4-axis decomposition | Single reward insufficient for multi-faceted interactivity |
| DuplexSLA's 3-channel architecture | Need for parallel user audio + assistant audio + action planning |
| ASPIRin's Action Space Projection | Raw-token GRPO causing >50% duplicate n-grams |
| LLM Judge Anchor (new) | Reward hacking via incomplete responses (SteerDuplex documented) |
| WavAlign's Modality-Aware Mask | Acoustic model degradation during axes RL updates |

## 6.2 Main contributions

This proposal makes the following contributions:

**Contribution 1 — First systematic implementation of multi-axis RL on a 30B-scale FD dialogue model.** Existing work has demonstrated multi-axis RL on 7B–10B models (MFIA on Moshi/PersonaPlex; ASPIRin). We extend this to 30B, demonstrating that the multi-axis decomposition scales.

**Contribution 2 — LLM Judge Anchor mechanism.** We propose using a frozen LLM (Qwen2.5-72B) as a non-degrading semantic quality judge to gate axes training. This addresses the reward-hacking failure mode documented by SteerDuplex and provides a generalizable approach for any behavioral RL on large models.

**Contribution 3 — Integration of 5 recent insights into a unified framework.** We show that MFIA, DuplexSLA, ASPIRin, WavAlign, and Cocktail-Talker can be combined coherently, with each addressing a complementary failure mode.

**Contribution 4 — Comprehensive evaluation methodology.** We provide a 4-axis evaluation framework spanning 9 standardized benchmarks (MMAE, HumDial, APEX-Voice, SteerBench, etc.) plus 5 ablation studies plus human evaluation protocol.

**Contribution 5 — Open-source contributions.** All training code, evaluation scripts, model weights (LoRA), and benchmark contributions will be released open-source.

## 6.4 Expected contributions to the field

### 6.4.1 Methodological contributions

- **Demonstration that multi-axis RL scales to 30B parameters.** Previous work was limited to 7B-10B; this proposal validates 30B.
- **LLM Judge Anchor as a general mechanism** for protecting semantic quality during behavioral RL on large models.
- **Integration framework** showing how to combine MFIA + DuplexSLA + ASPIRin + WavAlign + Cocktail-Talker into a unified training pipeline.

### 6.4.2 Empirical contributions

- **Comprehensive evaluation** of 4-axis RL on 30B model across 9 benchmarks.
- **5 ablation studies** isolating contribution of each component.
- **Human evaluation** on 200 conversations with rigorous inter-rater agreement.

### 6.4.3 Practical contributions

- **Open-source code release** for training pipeline, evaluation scripts, and benchmarks.
- **Model weights release** (QwenOmni-3 30B + LoRA adapters).
- **Benchmark contribution** to the research community.

## 6.5 Conclusion

This proposal presents a complete, well-motivated, and technically grounded approach to scaling full-duplex spoken dialogue model RL to 30B parameters. By integrating five recent methodological insights (MFIA, DuplexSLA, ASPIRin, WavAlign, Cocktail-Talker) and adding a new LLM Judge Anchor mechanism, we address all known failure modes of behavioral RL on large full-duplex models.

The expected outcomes — improved interactivity metrics across all four axes while preserving semantic quality, robust multi-speaker noisy performance, and steerable behavior — position this work as a meaningful contribution to industrial deployment of natural voice agents.

The proposed 12-month timeline and ~50K GPU hours compute budget are realistic given the scope and the maturity of the underlying methods. The open-source release plan ensures that the contributions benefit the broader research community.

We believe this proposal represents a timely and important step toward natural, robust, semantically-grounded full-duplex spoken dialogue at industrial scale.
