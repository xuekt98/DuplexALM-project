## 2.1 全双工口语对话：从级联流水线到原生架构

口语对话系统的全双工（full-duplex）特性——即同时监听与生成、允许用户随时打断并自然地处理副语言反馈（backchannel）——是构建自然人机语音交互的核心能力。早期系统多采用**级联（cascaded）流水线**：自动语音识别（ASR）→ 文本对话模型 → 文本转语音（TTS），并通过语音活动检测（VAD）强制半双工 turn-taking。该范式易于接入大语言模型（LLM）的语义能力，但在长对话中会累积延迟，且 VAD 强制切分 turn 经常导致不自然的对话节奏。

为突破这些限制，dGSLM（Nguyen et al., 2023）率先用 HuBERT 离散单元加双塔 Transformer 在无文本情况下构建 spoken dialogue 系统，证明了 textless 路径的可行性。Moshi（Défossez et al., 2024）则代表了关键转折点：它用 4-stream interleaved token 加 Mimi codec 加单 backbone，在 200 ms 量级实现真正的全双工，成为后续多数研究的 reference baseline。SALMONN-omni（Yu et al., 2024）和 Mini-Omni2（Xie et al., 2024）则探索了 codec-free 或 stream-of-speech 的训练范式，进一步降低了工程门槛。

在工业界，OpenAI Realtime API、Google Gemini Live、Moshi（Kyutai）、Step-Audio 等系统已在 2025–2026 年密集落地。但一个共同的结构性问题是：**现有全双工模型主要用 token-level likelihood maximization 训练，并未直接优化交互行为**（Défossez et al., 2026a）。这导致"过度沉默、turn-taking 不准、副语言错位、barge-in 响应差"等典型的 interactivity 失败模式。

## 2.2 Turn-taking 与交互建模

Turn-taking 是全双工系统的核心交互行为。早期语义 VAD 方法用停顿阈值或声学特征判定 turn 边界，但缺乏对话上下文。JAL-Turn（2603.26515）通过 acoustic-linguistic 联合建模改进 turn-taking 检测，但仍是模块化设计。HiThink Turn（2609.34096）等把 intent 作为显式建模目标。

进一步，端到端的 turn-taking 优化被提出。AdaptDuplex（2609.29217）通过自适应策略让 turn-taking 模型从静态转向动态。Voice-Light（2609.20995）结合 causal 与 speculative generation 实现流式 turn-taking。Controlling Backchannels（2609.29418）单独优化副语言（"嗯" "对"等）的触发时机。Cocktail-Talker（Xin et al., 2026）首次在嘈杂多人场景中通过 Turn Action GRPO 联合优化"何时开口"与"对谁开口"。

这些工作共同构成了**全双工交互建模从模块化走向端到端**的趋势，但仍存在三个开放问题：(1) turn-taking 优化常以牺牲语义为代价；(2) 副语言与 barge-in 的训练数据稀缺；(3) 缺乏对多种交互 axis 的统一奖励框架。

## 2.3 口语对话系统中的强化学习

强化学习（RL）在大语言模型对齐中取得显著成功（RLHF、RLAIF、GRPO、DPO），但其在口语对话系统（SDS）中的应用仍处于早期。已有工作大致可分为三类。

**第一类：在 token-level 空间直接做 RL**。Optimizing Conversational Quality in SDS with RLAIF（Zhang et al., 2026a）是首篇将 multi-reward RLAIF 应用于 SDS 的工作，结合 semantic quality、audio naturalness、emotion consistency 三个 reward，用 turn-level preference sampling 在 blockwise duplex model 上做 DPO。Aligning Spoken Dialogue Models from User Interactions（Lin et al., 2025）则用 15 万对偏好数据做 offline preference alignment。WavAlign（Wang et al., 2026）提出 modality-aware 自适应 post-training，把 RL 更新限制在 semantic channel，避免对 acoustic 行为的扰动。

**第二类：把交互行为作为独立 RL 目标**。ASPIRin（Chen et al., 2026）针对 raw-token RL 容易导致 repetition 的问题，提出 Action Space Projection——把 text vocab 投影到二元状态（speech / silence），用 GRPO 加 rule-based rewards 优化 turn-timing 行为，实验中重复 n-gram 减少 50% 以上。Decoupling Conversational Dynamics in Full-Duplex Spoken Models through Reinforcement Learning（Wu et al., 2026）提出 DuplexPO 框架，用 Factorized Conversational Dynamics Reward（FCDR）做精细化的 temporal credit assignment（turn initiation、backchanneling、yielding、regularized participation），用 GRPO-style objective 优化。Cocktail-Talker（Xin et al., 2026）的 Turn Action GRPO 同样在多人嘈杂场景中验证了 per-axis RL 的可行性。

**第三类：reward model 本身的设计**。Dual-Axis Generative Reward Model（Liu et al., 2026）针对 SDS 设计了 dual-axis reward（semantic 加 timing），解决了"automated metric 太肤浅、human eval 太昂贵"的两难困境。SteerDuplex（Zhang et al., 2026b）则用两阶段 RL（verifiable interaction checks 加 judge-based semantic feedback）实现 steerability 优化，并发现 reward hacking 风险——模型可能学到 incomplete response 来通过 timing reward。

Step-Audio-R1（StepFun, 2025）首次把 R1-style reasoning RL 迁移到 audio LALM。Multi-Faceted Interactivity Alignment（Défossez et al., 2026a）则提出最完整的 4-axis 框架（pause handling、turn-taking、backchanneling、user interruption）加 LLM judge anchor，已在 Moshi 和 PersonaPlex 上验证。

这些工作形成了一个清晰的研究脉络：**RL 在 SDS 中逐步从单一维度（仅语义或仅 turn-taking）扩展到多维联合优化**，但**仍存在显著缺口**——具体见 §2.5。

## 2.4 评测基准与数据集

全双工系统的评测需要同时衡量**语义正确性**与**交互自然度**。早期评估借用 ASR/TTS 指标（WER、MOS），无法捕捉交互质量。Moshi 时代起出现了专门的 benchmark：FD-Bench（2507.19040）首次构建 multi-turn 评测协议；HumDial Challenge（ICASSP 2026, 2604.21406）建立官方 standard；M3-DuplexBench（2607.29125）覆盖 multi-turn、multilingual、multidomain；APEX-Voice（2609.34973）专注 120 个 professional workflows；DuplexSpeechBench-IFEval（2609.03423v2）评估 implicit instruction following；IndicFDB（2609.31967）覆盖印度语言；SpeechEQ（2606.25990）评估情感智商。

数据集方面：DuplexChat（2607.04941）提供 speaker-separated full-duplex 数据；DuplexDrama（2609.12872v2）涵盖 scenarios 加 expressive speech 加 sound events；ConversationalVoice（2609.08147）来自真实对话；Aligning Spoken Dialogue Models（Lin et al., 2025）发布 15 万 preference pairs。

然而，**针对大型基础模型（>10B 参数）加多轴交互加 RL 训练的统一 benchmark 仍缺失**。现有评测多为 sub-10B 模型设计，无法直接评估 30B 级模型的 RL fine-tuning 效果。

## 2.5 研究空白与本研究定位

综合以上文献，全双工口语对话模型的 RL 研究仍存在三个关键空白。

**空白一：模型规模受限**。当前 E2E 加 RL 的十篇工作中，最常应用的 baseline 是 Moshi（约 7B）、PersonaPlex（约 7B）和 SALMONN-omni（不到 10B）。**针对 30B 级开源全双工基础模型（如 QwenOmni-3 30B）的 RL 微调仍是空白**。QwenOmni-3 30B 在多模态理解上具有强能力，但其在全双工交互上的 RL 适配尚未被系统研究。

**空白二：单一交互 axis 优化为主**。已有 RL 研究往往聚焦单一交互 axis（如仅 turn-taking 或仅 barge-in），缺乏统一的 multi-axis 框架。Multi-Faceted Interactivity Alignment（Défossez et al., 2026a）虽提出 4-axis 框架并应用在 Moshi 与 PersonaPlex，但**尚未在 30B 量级模型上验证**。

**空白三：缺乏"语义 vs 交互"的稳定权衡**。ASPIRin 已显示 raw-token RL 会导致 repetition；WavAlign 提出 modality-aware RL；MFIA 提出 LLM judge anchor。**这些权衡机制在 30B 量级模型上的效果与可扩展性仍未验证**。

针对上述空白，本研究（详见第 3 章）拟在 QwenOmni-3 30B 上系统实现并验证多轴交互对齐方法，结合 MFIA 的 4-axis 框架、ASPIRin 的 Action Space Projection 和 LLM Judge anchor reward，构建可扩展的全双工口语对话 RL 训练方案，并在统一 benchmark 上评估其相对 SFT baseline 的提升。
