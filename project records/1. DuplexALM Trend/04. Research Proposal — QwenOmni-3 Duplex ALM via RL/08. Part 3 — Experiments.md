### 4.1.3 Implementation details

All training and evaluation use the same QwenOmni-3 30B base. LoRA fine-tuning employs rank r=64 on LLM backbone and speech decoder; rank r=8x on action channel and axis heads; rank r=8 on axis-specific LoRAs. Total trainable LoRA parameters: ~250M.

Training infrastructure: 32× H100-80GB GPUs, ~50K GPU hours total. The 4 axis-specific RL stages run in parallel where dependencies permit.

LLM Judge uses frozen Qwen2.5-72B with axes_weight gating (axes_weight = max(0, (semantic_score - 0.4) / 0.6)).

## 4.2 Evaluation methodology

### 4.2.1 Per-axis metrics

Each axis is evaluated with axis-specific metrics that reflect human-like behavior:

**Axis 1 — Pause handling.**
- *Metric 1.1:* KL divergence between model-generated pause-duration distribution and human ground-truth pause-duration distribution. Target: KL < 0.05.
- *Metric 1.2:* Pause rate (fraction of user-turn-end → assistant-response intervals with deliberate silence > 500ms vs. no silence).
- *Metric 1.3:* Backchannel-conditional pause consistency (fraction of pauses accompanied by an appropriate backchannel).

**Axis 2 — Turn-taking.**
- *Metric 2.1:* Turn-taking latency p50 and p95 (time from turn-end to first speech token). Target: p50 < 300 ms, p95 < 800 ms.
- *Metric 2.2:* End-to-end conversation success rate at HumDial Challenge (offline + real-time).
- *Metric 2.3:* FD-Bench multi-turn evaluation score (consistency, instruction following).

**Axis 3 — Backchanneling.**
- *Metric 3.1:* Backchannel appropriateness score (LLM judge on whether backchannels are appropriately placed and timed).
- *Metric 3.2:* Backchannel false-positive rate (unnecessary backchannels).
- *Metric 3.3:* SpeechEQ emotional intelligence score.

**Axis 4 — Interruption.**
- *Metric 4.1:* Graceful yield rate (fraction of barge-in scenarios where the model yields appropriately).
- *Metric 4.2:* Interruption response latency p50/p95.
- *Metric 4.3:* APEX-Voice task success rate on 120 professional workflows.

### 4.2.2 Cross-axis metrics

- *Joint axis coherence:* Probability that 4 axes produce mutually consistent actions (e.g., backchanneling during pause but not before speaking).
- *Conversation MOS:* Human Mean Opinion Score on a 5-point scale, evaluated by ≥3 human raters per conversation.
- *Preference A/B test:* Head-to-head win rate of proposed method vs. each baseline (forced choice, blinded).

### 4.2.3 Semantic quality metrics

- *LLM Judge semantic score:* Frozen Qwen2.5-72B on response quality (factual, relevant, safe). Target: > 0.6 throughout.
- *ASR WER:* Whisper-large-v3 transcription of model outputs.
- *UTMOS / NISQA:* Audio quality metrics on generated speech.

### 4.2.4 Robustness metrics

- *Noise robustness:* Performance drop under SNR 5 dB vs. clean (on Cocktail-Talker Eval).
- *Multi-speaker robustness:* Performance drop under 3+ speaker overlap scenarios.
- *Cross-lingual robustness:* Performance on IndicFDB (Indian languages).

## 4.3 Experimental procedure

The evaluation procedure is:

1. **Trained model inference.** For each test conversation, run the proposed model end-to-end (audio → LLM backbone → 4-axis heads + action stream → speech decoder).

2. **Per-axis metric computation.** Compute Axis 1–4 metrics on model outputs vs. ground-truth annotations.

3. **Cross-axis coherence.** Verify that the 4 axis decisions are mutually consistent across a conversation.

4. **Semantic quality evaluation.** Run LLM Judge (Qwen2.5-72B) + human raters on model outputs.

5. **Robustness evaluation.** Re-run evaluation under noise / multi-speaker / cross-lingual conditions.

6. **Statistical significance.** For each comparison, run 1000 bootstrap samples to compute 95% confidence intervals. Report p-values where applicable.

7. **Ablation studies.** Re-run baselines without each component to isolate contribution.

### 4.4.2 Ablation studies

**Ablation 1: Contribution of each axis.**

- Without Axis 1 (pause): expected ~15% degradation in pause KL divergence.
- Without Axis 2 (turn): expected ~150ms increase in latency p50.
- Without Axis 3 (backchannel): expected ~25% drop in appropriateness score.
- Without Axis 4 (interruption): expected ~20% drop in graceful yield rate.

**Ablation 2: ASPIRin's Action Space Projection.**

- Without ASP (raw-token GRPO): expected ~30% increase in duplicate n-gram ratio (consistent with ASPIRin's reported finding of >50% reduction).

**Ablation 3: LLM Judge Anchor.**

- Without anchor: expected severe semantic degradation (Conversation MOS drops by 0.4–0.6 points).
- Without anchor gating: axes training may produce reward-hacking artifacts (SteerDuplex-reported phenomenon).

**Ablation 4: WavAlign Modality-Aware Mask.**

- Without mask: expected degradation in audio quality (UTMOS) due to acoustic model damage.

**Ablation 5: Stage 3 Joint Refinement.**

- Without Stage 3: expected slight degradation in cross-axis coherence; per-axis metrics largely unchanged.

### 4.4.3 Robustness experiments

**Noise robustness.** Cocktail-Talker Eval performance drop from clean (SNR > 20 dB) to noisy (SNR = 5 dB):
- Proposed method: expected <10% drop.
- Baselines without explicit noise augmentation: expected 20–30% drop.

**Multi-speaker robustness.** Performance under 3+ speaker overlap scenarios:
- Proposed method: expected <12% drop.
- Baselines: expected 25–35% drop.

**Cross-lingual robustness.** IndicFDB (Indian languages) performance:
- Proposed method: expected moderate degradation (training data English-dominant).
- Future work: extend to multilingual training.

### 4.4.4 Compute efficiency

The proposed method consumes **~50K GPU hours total** for training, comparable to single 30B model pretraining. The Stage 2 RL stages run in parallel, reducing wall-clock time to ~2-3 weeks on 32 H100-80GB nodes.

## 4.5 Human evaluation protocol

A subset of 200 conversations is evaluated by ≥3 human raters per conversation. Raters score:
- **Naturalness** (1–5): How natural does the conversation feel?
- **Engagement** (1–5): Does the model maintain engagement?
- **Appropriateness** (1–5): Are responses contextually appropriate?
- **Helpfulness** (1–5): Does the model accomplish the task?

Inter-rater agreement target: Cohen's κ ≥ 0.6.

## 4.6 Summary of experimental design

| Aspect | Choice | Rationale |
|---|---|---|
| **Baselines** | 7 ablations + 4 external | Isolate contributions + situate vs. SOTA |
| **Benchmarks** | 9 standardized + held-out | Comprehensive coverage of 4 axes + semantic |
| **Metrics** | 4 axis + 3 cross-axis + 3 semantic + 3 robustness | Multi-dimensional evaluation |
| **Ablations** | 5 dimensions | Each component justified |
| **Human eval** | 200 conversations × 4 dimensions × 3 raters | Gold-standard ground truth |
| **Statistical** | 1000-bootstrap 95% CI | Robust significance testing |
