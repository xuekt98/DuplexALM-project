## 2.1 Background: From Cascaded to Native Full-Duplex Dialogue

### 2.1.1 Three structural limitations of cascaded systems

Spoken dialogue systems have evolved from **cascaded** to **native** architectures. The cascaded paradigm stacks ASR → text dialogue model → TTS in series, with turn-taking enforced by an independent Voice Activity Detection (VAD) module. While this architecture is convenient for integrating LLM semantic capabilities, it suffers from three structural limitations:

1. **Sequential latency of seconds** between interactions due to module chaining.
2. **Loss of non-semantic information** (emotion, prosody, non-speech sounds) forced into a text intermediate representation.
3. **VAD-enforced half-duplex turns** that cannot handle barge-in, overlapping speech, or interjections.

### 2.1.2 The native paradigm breakthrough: Moshi

**Moshi** (Défossez et al., 2024, arXiv:2410.00037) represents the pivotal breakthrough. Its complete method, in the authors' own framing:

- **Cast spoken dialogue as speech-to-speech generation**, abandoning VAD and explicit turn segmentation.
- **Starting from a text language model backbone**, Moshi generates speech as tokens from the **residual quantizer of a neural audio codec** (Mimi).
- **Modeling the assistant's speech and the user's speech as parallel streams**, enabling genuine full-duplex interaction.
- **The "Inner Monologue" method**: predict time-aligned text tokens as a prefix to audio tokens, extending hierarchical semantic-to-acoustic token generation.
- Achieves **160 ms theoretical / 200 ms practical first-audio-token latency** — the first real-time full-duplex spoken LLM. Open source at https://github.com/kyutai-labs/moshi.

**SALMONN-omni** (Yu et al., 2024, arXiv:2411.18138) explores a **codec-free** path, using LLM hidden states directly to generate semantic and acoustic features, avoiding codec tokenization loss. **Mini-Omni2** (Xie et al., 2024, arXiv:2410.11190) provides an open-source implementation of real-time voice dialogue with vision extension.

### 2.1.3 A fundamental defect: interactivity is not optimized

**MFIA** (Défossez et al., 2026a, arXiv:2606.11167v2) provides the canonical diagnosis:

> "Current models are trained solely with supervised learning through token-level likelihood maximization, **which does not directly optimize interaction-level behaviors**, causing interactivity issues such as excessive silence and ill-timed turn-taking. Recent work has applied reinforcement learning (RL) to improve interactivity, but **existing methods address only a limited set of interactive behaviors in their rewards**."

This diagnosis forms the central motivation for our study: RL is the natural path to directly optimize interaction behaviors, but the multi-axis nature of interactivity requires a unified framework.

## 2.2 Turn-Taking and Interaction Modeling

Early approaches used semantic VAD with silence-duration or speaking-rate thresholds. More recent work moves toward end-to-end decision-making:

- **JAL-Turn** (arXiv:2603.26515) improves turn-taking detection via acoustic-linguistic joint modeling, but remains modular.
- **AdaptDuplex** (arXiv:2609.29217) moves from static to adaptive turn-taking via RL-based policy.
- **Voice-Light** (arXiv:2609.20995) combines causal and speculative generation: speculative tokens are generated during user speech, committed when the user pauses — avoiding latency penalty.
- **Controlling Backchannels** (arXiv:2609.29418) focuses specifically on paraling-timing of trigger.

## 2.3 Reinforcement Learning for Spoken Dialogue Systems

This section systematically organizes the rapidly growing RL literature for spoken dialogue systems (SDS) into five method categories. Each paper contributes a specific technical insight that we synthesize for our 30B-scale approach.

### 2.3.1 Multi-Axis unified framework (the core method)

**MFIA — Multi-Faceted Interactivity Alignment** (Défossez et al., 2026a, arXiv:2606.11167v2). This is the core methodological foundation of our study.

```
Algorithm: MFIA Post-Training Alignment
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Input: SFT model π_SFT, human conversation corpus D
Output: Aligned model π_RL

1.  Define axes: A = {pause, turn, backchannel, interrupt}
2.  For each axis a ∈ A, extract segments D_a from D matching axis a
3.  Define anchor reward R_LLM via LLM-as-judge on response quality
4.  Combined reward: R_total = α · R_LLM + (1-α) · Σ_a λ_a · R_a
5.  Optimize: π_RL = argmax_π E[R_total] with axis-specific RL algorithm
```

**Key contributions**:
- **Four canonical axes of interactivity**: pause handling, turn-taking, backchanneling, user interruption.
- **Axis-specific reward functions**: each axis has a tailored reward (e.g., `R_pause`: silence-duration distribution match; `R_turn`: 200-800ms latency target; `R_backchannel`: appropriate moment + signal; `R_interrupt`: graceful yield + response time).
- **LLM-based anchor reward** for response quality, **preventing axes training from degrading semantic capability** (the key risk identified across RL literature).
- Applied to Moshi (~7B) and PersonaPlex (~7B); consistent improvements in offline and real-time evaluation.

**Decoupling Conversational Dynamics — DuplexPO** (Wu et al., 2026, arXiv:2607.07148v1). The companion work that articulates the same insight from a different angle:

> "Such an intelligence-dynamics trade-off is not fundamental: conversational dynamics can instead be learned as a separate real-time decision policy from human dialogue data."

**Method**:
- Preserve the semantic response capability of an instruction-tuned assistant.
- Optimize temporal interaction behavior on **selected high-impact windows** from long human conversations.
- **Factorized Conversational Dynamics Reward (FCDR)** with four fine-grained components: `turn_initiation`, `backchanneling`, `yielding`, `regularized_participation`.
- Trained with **GRPO-style objective**.

MFIA uses **axis-specific** rewards; DuplexPO uses **factorized FCDR** rewards — both decompose interactivity into complementary dimensions and treat them as separate RL targets.

### 2.3.2 Speech-Language-Action architecture for agentic behavior

**DuplexSLA** (Zhang et al., 2026, arXiv:2605.20755v2) addresses a complementary architectural problem: existing duplex backbones lack a native channel for **in-conversation planning and tool calling**, leaving real-time agentic behavior either tied to turn boundaries or relegated to an external cascade.

```
Algorithm: DuplexSLA Three-Channel Decoding
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
At each 160ms clock tick:
1.  User audio channel (continuous):
      u_t = AudioEncoder(user_audio_chunk_t)
2.  Assistant audio channel (discrete):
      a_t = AutoregressiveSample(model.a_history, u_t)
3.  Action channel (rate-limited text):
      action_t = AutoregressiveSample(model.action_history, u_t, a_t)
4.  Action types: continue_speak, pause, backchannel, tool_call
5.  Concatenate outputs as joint next-token distribution

Training (3-stage):
1.  Pre-training: text LLM + audio tokens
2.  SFT: Multi-turn dialogues with action annotations
3.  RL: Action channel optimized via PPO/RLHF
```

**Three-channel formulation**:

```
┌────────────────────────────────────────────────────────┐
│  Single Backbone (Qwen-style LLM)                       │
│                                                         │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐        │
│  │ Channel 1   │ │ Channel 2   │ │ Channel 3   │        │
│  │ User Audio  │ │ Asst Audio  │ │ Action      │        │
│  │ (continuous)│ │ (discrete)  │ │ (text)      │        │
│  └─────────────┘ └─────────────┘ └─────────────┘        │
│         │              │              │                 │
│  160ms chunk      160ms chunk    160ms chunk           │
└────────────────────────────────────────────────────────┘
              ↓ shared clock ↓
```

**Key innovations**:

1. **Shared 160 ms chunk timeline**: three channels on the same clock, decoded jointly by a single backbone. Listening, speaking, planning, and tool calling unfold on one shared timeline.
2. **Semantic-driven turn-taking control** (Capability 1): interruption, pause, backchannel handled inside the same backbone, replacing external semantic VAD.
3. **In-conversation planning + tool calling** (Capability 2): planning text and structured tool calls emitted on the action channel **without halting assistant audio**, so backchannel-triggered tool use is interleaved with ongoing speech.
4. **DuplexSLA-Bench**: evaluates pause, interrupt, backchannel turn-taking + 3 styles of in-conversation tool calling.

Open source: https://github.com/hyzhang24/DuplexSLA.

**Relevance to our study**: DuplexSLA provides the **3-channel architectural design** that our 4-axis RL training targets. The action channel is the natural place to attach RL rewards: axis-specific RL optimizes action channel outputs (e.g., pause handling → <|pause|> action; turn-taking → <|speak|> action timing; backchanneling → <|backchannel|> action; user interruption → <|yield|> or <|continue|> action). The 160 ms chunk timeline aligns with our 300 ms first-token latency target.

### 2.3.3 Action Space Projection (preventing RL degeneration)

**ASPIRin** (Chen et al., 2026, arXiv:2604.10065v1) addresses a critical failure mode of standard RL on duplex models:

> "Optimizing temporal dynamics via standard raw-token reinforcement learning (RL) **degrades semantic quality**, causing severe generative collapse and repetition."

```
Algorithm: ASPIRin Action Space Projection + GRPO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Standard GRPO problem: degrades semantic quality

ASPIRin solution:
1.  Action Space Projection: V → V_proj (binary state)
      active_speech ↔ inactive_silence
2.  Modified GRPO: optimize π(action_state | context)
3.  Rule-based rewards:
      - balanced interruption
      - response latency (100-800ms target)
```

**Key result**: **reduces duplicate n-grams by over 50%** compared to standard GRPO, effectively eliminating degenerative repetition. This is critical for our 30B-scale study — the binary action projection preserves the semantic capability of the underlying LLM.

### 2.3.4 Multi-speaker noisy environment turn actions

**Cocktail-Talker** (Xin et al., 2026, arXiv:2607.27756v1) extends duplex modeling to **multi-speaker noisy social environments**, addressing a different failure axis than MFIA or ASPIRin.

```
Algorithm: Cocktail-Talker Turn Action GRPO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Action tokens: A = {<|respond|>, <|listen|>, <|ignore|>}

Stage 1: Data Generation (Cocktail-DialogGen)
  - LLM simulates multi-speaker dialogs
  - Speaker roles across diverse social settings
  - Edge cases: ambiguous / irrelevant speech

Stage 2: Supervised Finetuning
  L = CE(action_token_target, action_pred) 
    + CE(text_response, text_pred)  // only for respond
    + CE(audio_response, audio_pred)

Stage 3: Turn Action GRPO
  For each conversation, for each turn-action decision:
    - Sample G=8 candidate actions
    - Compute reward R = LLM_judge(action_quality, scene_understanding)
  GRPO loss: L = -E[advantage · log_prob]
  advantage = (R - mean(R)) / std(R)
```

Cocktail-Talker solves **"whether to speak at all"** (in addition to "when to speak"), which is orthogonal to MFIA's axis decomposition.

### 2.3.5 Reward model design

**Dual-Axis Generative Reward Model** (Liu et al., 2026, arXiv:2604.14920v1) addresses a fundamental barrier: prevailing automated metrics rely on superficial proxies (behavioral statistics or timing-prediction accuracy), while human evaluation is costly and inconsistent.

**Method**: Train a Generative Reward Model with detailed taxonomy and annotated dataset. Output **single score + separately semantic quality and interaction timing scores**. State-of-the-art on interaction-quality assessment, suitable for online RL.

### 2.3.6 Modality-aware RL (preventing acoustic degradation)

**WavAlign** (Wang et al., 2026, arXiv:2604.14932v1) identifies a subtle failure mode: sparse preference supervision interacts poorly with dense speech generation under shared-parameter updates.

**Method**: Constrain preference updates to the **semantic channel**; improve acoustic behavior via **explicit anchoring**; dynamically regulate mixture from rollout statistics. Consistent improvements in semantic quality and speech expressiveness.

This insight is critical for our 30B-scale study — preventing RL from degrading the underlying acoustic model.

### 2.3.7 Direct alignment (RLAIF/DPO)

**Optimizing Conversational Quality in SDS with RLAIF** (Zhang et al., 2026a, arXiv:2601.19063v1). The first **multi-reward RLAIF** for SDS:

- Multi-reward: semantic quality + audio quality + emotion consistency.
- Turn-level preference sampling adapted to blockwise duplex decoding.
- Per-block log-probability aggregation in the DPO objective.
- Key finding: joint multi-reward training yields **stable** improvements in semantic quality and audio naturalness.

**Aligning Spoken Dialogue Models from User Interactions** (Lin et al., 2025, arXiv:2506.21463v1). Offline DPO with **150K preference pairs** from raw multi-turn speech conversations + AI feedback, targeting both linguistic content and temporal context variations.

### 2.3.8 Reasoning RL

**Step-Audio-R1 Technical Report** (StepFun, 2025, arXiv:2511.15848v2). First audio reasoning model via **Modality-Grounded Reasoning Distillation (MGRD)**: generates audio-relevant reasoning chains grounded in acoustic features (not disconnected deliberations). Surpasses Gemini 2.5 Pro on audio reasoning.

**The Silent Thought: FLAIR** (Wang et al., 2026, arXiv:2603.17837v5). Latent reasoning during user speaking via recursive embedding updates. Uses **ELBO-based objective** for supervised fine-tuning with teacher forcing — no reasoning annotation needed, no latency penalty.

### 2.3.9 Role and voice control

**PersonaPlex** (arXiv:2602.06053v1). Hybrid system prompts combining role conditioning (text) with voice cloning (speech samples). Trained on synthetic paired-prompt dataset (LLM + TTS generated). Surpasses SOTA in role adherence, speaker similarity, latency, and naturalness.

### 2.3.10 Steerability with reward-hacking warning

**SteerDuplex** (Zhang et al., 2026c, arXiv:2609.12623v1) targets the underexplored capability of **steerability** — shifting conversational behavior along tone, persona, speaking rate, voice style.

**Method**: Moshi-based FD speech model + SFT on natural conversations and synthetic dialogues + **two-stage RL with hybrid rewards**:
- Verifiable interaction checks (timing, barge-in)
- Judge-based semantic feedback (LLM judge)

**SteerBench**: 390 spoken prompts + 1,067 human-authored binary audio/text rubrics.

**Key experimental results**:
- SFT improves audio-steering average pass rate **+44.5 pp** vs strongest open baseline.
- **Source-clean interruption response**: 72.5% → 82.5% (+RL).
- **Synthetic pause barge-in**: 26.5% → 9% (+RL).

**Critical finding — reward hacking risk**:

> "Reward probes reveal **reward hacking through incomplete responses**. Our model and benchmark support systematic research on spoken steerability, with reward analysis showing why timing gains must be evaluated alongside response completeness."

This finding reinforces the necessity of an **LLM-based anchor reward** (MFIA's key design) to prevent axes training from degrading response completeness.

## 2.5 Research Gap and Positioning

Synthesizing the above literature, three critical gaps remain in full-duplex spoken dialogue model RL research.

### 2.5.1 Gap 1: Limited model scale

The most commonly used bases for existing RL work are **Moshi (~7B)**, **PersonaPlex (~7B)**, and **SALMONN-omni (<10B)**. **RL fine-tuning of 30B-scale open-source full-duplex foundation models (such as QwenOmni-3 30B) remains an open gap**. QwenOmni-3 30B has strong multimodal understanding, existing audio adaptation, and the compute resources to support RL training, but its RL adaptation for full-duplex interaction has not been systematically studied.

### 2.5.2 Gap 2: Single-axis optimization

Existing RL work often focuses on a single axis: ASPIRin (timing only), Dual-Axis GRM (semantic + timing only), Cocktail-Talker (respond/listen/ignore only). **Multi-Faceted Interactivity Alignment (MFIA) proposes a 4-axis structure** (pause handling / turn-taking / backchanneling / user interruption), but **it has been verified only on Moshi (~7B) and PersonaPlex (~7B)**; its scalability to 30B models has not been validated.

### 2.5.3 Gap 3: Lack of stable "semantic vs. interaction" trade-off

- **ASPIRin** has shown that raw-token RL leads to repetition.
- **WavAlign** proposes modality-aware RL (semantic channel updates only).
- **MFIA** proposes LLM-as-judge anchor reward.
- **SteerDuplex** discovered the reward-hacking risk (model learns to produce incomplete responses).

The effectiveness and scalability of these trade-off mechanisms on 30B models remain unverified. Three specific questions:
1. How should the anchor reward weights be adjusted for 30B models?
2. Are 30B models more susceptible to reward hacking?
3. Does WavAlign's modality-aware approach still work at larger scale?

### 2.5.4 Study positioning

To address the above gaps, this study (see Chapter 3) implements on QwenOmni-3 30B:

1. **MFIA's 4-axis framework** with the best-fitting RL method per axis:
   - **Pause Handling**: **DPO** (binary decision)
   - **Turn-Taking**: **GRPO + ASPIRin's Action Space Projection**
   - **Backchanneling**: **Conditional DPO** (conditional on whether the other party is speaking)
   - **Interruption**: **Policy Gradient + FSM state machine**

2. **Preserve ASPIRin's core insight**: Action Space Projection maps vocabulary to binary state, avoiding raw-token RL repetition.

3. **Preserve MFIA's LLM Judge anchor**: preventing axes training from semantic collapse.

4. **Incorporate WavAlign's modality-aware insight**: RL updates restricted to semantic channel, acoustic behavior improved via explicit anchoring.

5. **Evaluate on unified benchmarks**: MMAE + DuplexBench + APEX-Voice + Cocktail-Talker Eval.

The core contribution of this study is the **first systematic implementation and validation of multi-axis interaction alignment on a 30B-scale full-duplex model**, providing a scalable methodology for RL training of industrial-grade (30B+) full-duplex systems.
