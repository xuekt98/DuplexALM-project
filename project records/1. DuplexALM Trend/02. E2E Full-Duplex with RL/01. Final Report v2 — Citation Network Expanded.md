## 摘要（Abstract）

本版本通过 Semantic Scholar 引用网络分析，将 4 篇扩到 **10 篇**真正 end-to-end + RL 的全双工对话论文。引用网络揭示了 **4 个核心 anchor（Multi-Faceted Interactivity / Decoupling / ASPIRin / Dual-Axis GRM）**之间的相互引用关系。关键技术发现：

- **DPO 已被使用**（被 2506.21463 和 2601.19063 使用）——上一版本说 0 篇是错的

- **GRPO 占主流**（4/10 篇：Cocktail-Talker, Decoupling, ASPIRin, Dual-Axis-GRM）
- **新增 WavAlign**（modality-aware RL with adaptive hybrid post-training）
- **新增 Aligning Spoken Dialogue Models from User Interactions**（offline preference alignment）

- **Cocktail-Talker** (2607.27756) — Turn Action GRPO

- **Dual-Axis GRM** — semantic + timing 双轴

- **FCDR** (2607.07148) — factorized conversational dynamics
- **SteerDuplex** (2609.12623) — verifiable + judge hybrid

### 5.3 Reasoning + RL

- **Step-Audio-R1** (2511.15848) — R1-style reasoning for audio
- **The Silent Thought (FLAIR)** (2603.17837) — latent reasoning (SFT-based, not RL)

- **Aligning Spoken Dialogue Models** (2506.21463) — DPO for FD S2S
- **Optimizing Conversational Quality** (2601.19063) — DPO with multi-reward
