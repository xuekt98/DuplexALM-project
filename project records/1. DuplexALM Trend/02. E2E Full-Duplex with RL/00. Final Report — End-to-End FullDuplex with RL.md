## 摘要（Abstract）

本研究聚焦"**端到端全双工口语对话模型**"（end-to-end full-duplex spoken dialogue model） + "**强化学习训练**"（reinforcement learning）的交集。2026-09 在 arXiv 检索，仅发现 **4 篇严格相关论文**——这是一个**极早期但快速增长**的 niche。4 篇论文全部集中于**解决同一个根本挑战**：直接用 RL 优化 turn-taking / barge-in / backchanneling 等互动行为会**牺牲语义质量**（甚至导致 degeneration / repetition）。**4 篇的共同技术路线是"解耦时间动态与语义生成"**——分别从 action space（ASPIRin）、reward design（Dual-Axis GRM）、policy factor（DuplexPO）、fine-tuning stages（SteerDuplex）切入。

## 3. 详细分析

### 3.1 Dual-Axis GRM (2604.14920)

**作者**：Jingyao 等
**核心问题**：RL 用于 SDMs 缺乏可靠 reward signal——automated metrics 依赖"行为统计"或"timing-prediction"，human eval 贵且不一致。
**核心贡献**：
- 训练一个 **Dual-Axis Generative Reward Model**（dual-axis GRM），理解复杂互动动态
- **一个 reward 给出两个独立分数**：semantic quality + interaction timing
- 可作为 **online RL 的 reward signal**
- 解决"reliable reward for FD-SDM RL"的核心障碍

**RL 算法**：Online RL with generative reward model

### 3.2 ASPIRin (2604.10065)

**作者**：Yifan 等
**核心问题**：End-to-end FD-SLMs 用 raw-token RL 优化 turn-taking 会**导致语义质量退化**（generative collapse + repetition）
**核心贡献**：
- **Action Space Projection**：把 text vocabulary 投影到 **coarse-grained binary state**（active speech vs. inactive silence）
- 用 **GRPO + rule-based rewards** 优化
- 平衡 user interruption + response latency
- 实验：**减少 duplicate n-grams 50% 以上**，消除 degeneration repetition

**RL 算法**：**GRPO**（Group Relative Policy Optimization）with Action Space Projection

### 3.3 DuplexPO (2606-07)

**作者**：Wen 等（推测浙大系）
**核心问题**：FD-SDM 的 conversational dynamics 改善会**削弱 reasoning + instruction-following**——存在 trade-off
**核心观点**：这种 trade-off **不是 fundamental**——conversational dynamics 可以作为**独立 real-time decision policy** 从人类对话数据中学习
**核心贡献**：
- **DuplexPO 框架**——**解耦 when to speak from what to say**
- 保留 instruction-tuned assistant 的语义响应能力
- 优化 temporal interaction behavior over high-impact windows from human conversations
- **Factorized Conversational Dynamics Reward (FCDR)**——fine-grained temporal credit assignment
  - turn initiation
  - backchanneling
  - yielding
  - regularized participation
- **GRPO-style** 优化

**RL 算法**：**GRPO-style** objective with FCDR

### 3.4 SteerDuplex (2609.12623)

**作者**：近期（2026-09-11）
**核心问题**：FD-SDM 的"steerability"被忽视——用户难以可靠控制 tone / persona / speaking rate / voice style
**核心贡献**：
- 提出 **steerability taxonomy**（text-based + audio-based）
- **Moshi-based FD model** + supervised fine-tuning + **two-stage RL with hybrid rewards**
- **Hybrid rewards**：
  1. **Verifiable interaction checks**（timing、barge-in）
  2. **Judge-based semantic feedback**（judge LM）
- 引入 **SteerBench**——390 spoken prompts + 1067 human-authored binary audio/text rubrics
- 关键数据：
  - **Source-clean interruption response**: 72.5% → 82.5% (RL 后)
  - **Synthetic pause barge-in**: 26.5% → 9% (RL 后)
  - **Audio MultiChallenge task avg pass rate**: +7 points
- ⚠️ **reward hacking** 风险——RL 优化时模型学到"incomplete response"来通过 timing reward

**RL 算法**：**Two-stage RL** with hybrid rewards

## 4. 跨论文综合

### 4.1 共同问题

| 问题 | 描述 |
|---|---|
| **Trade-off between dynamics and intelligence** | 优化 turn-taking / barge-in 会牺牲 reasoning + instruction-following |
| **RL instability** | Raw-token RL on speech tokens → generative collapse + repetition |
| **Reward design** | 缺乏可靠 reward signal——auto metrics superficial，human eval 贵 |

### 4.2 共同技术路线：**解耦时间动态与语义生成**

| 论文 | 解耦方式 |
|---|---|
| **ASPIRin** (2604.10065) | **Action Space Projection**——把 text vocab 投影到 binary state |
| **Dual-Axis GRM** (2604.14920) | **Reward 解耦**——一个 reward model 输出 semantic + timing 两轴分数 |
| **DuplexPO** (2607.07148) | **Policy 解耦**——把 conversational dynamics 作为独立 decision policy |
| **SteerDuplex** (2609.12623) | **Stage 解耦**——SFT → RL 两阶段；verifiable + judge 混合 reward |

**核心洞察**：**"when to speak" 与 "what to say" 应作为两个独立可优化模块**，避免 RL 在 raw token space 优化互动行为时破坏语义能力。

### 4.3 RL 算法分布

| 算法 | 论文 | 备注 |
|---|---|---|
| **GRPO** (Group Relative Policy Optimization) | ASPIRin, DuplexPO | DeepSeek-R1 思路迁移到 audio LALM；2026 H1 主流 |
| **Online RL with custom reward model** | Dual-Axis GRM | reward 模型本身作为基础设施 |
| **Two-stage RL with hybrid rewards** | SteerDuplex | SFT → RL pipeline；verifiable + judge |
| **PPO / DPO** | 无（0 篇） | 文本域主流，但端到端 FD-SDM 中未被使用 |

### 4.4 训练数据

- **Long human conversations**（含 high-impact windows）—— DuplexPO
- **Synthetic dialogues targeting specific behaviors**（turn-taking, barge-in, etc.）—— DuplexPO, SteerDuplex
- **SteerBench**：390 spoken prompts + 1067 rubrics（SteerDuplex）
